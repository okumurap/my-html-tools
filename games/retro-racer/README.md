# MINI KART PARK 箱庭カート

更新：2026-11-02（日本時間）。6コースでラジコン風の運転を楽しむ箱庭カートです。CP3台との3周レースと荷物集めを遊べます。コース編集機能は削除しました。外部通信・ライブラリ・ビルドは不要です。

## 操作

- 左ジョイスティックを上へ倒して加速、下へ倒してブレーキ・後退。倒す量で速度を調整
- 左を下へ倒し続けると、停止後に後退。離すと中立へ戻り、減速して停止
- 右ジョイスティックを左右へ倒して旋回。倒す量で旋回の強さを調整。最大旋回を従来の60%に抑えています。後退中は旋回方向が反転
- スマホでは両親指で同時操作できます。一方だけ離しても他方の操作は継続します
- PCは↑↓ / W Sで加減速、←→ / A Dで旋回。マウスでもジョイスティックを操作できます
- Spaceまたは中央ボタンで開始・一時停止・再開。新規開始・再プレイは3・2・1・GO!の後に発進します。一時停止からの再開はそのまま続行
- カウント中もスティックを構えて入力できます。発進までカート・CPとタイム計測は停止します
- フォーカスを失うと入力を解除して一時停止。カウント中に画面を離れると開始待ちをキャンセルし、スタート前へ戻ります
- コース・遊び方は停止中に変更できます。変更すると最初から準備します

カートは道の外も走れます。芝生では速度が落ちます。周回はコース上の進行距離で判定します。

## 保存

`mini-kart-park:records-rc-v1` にコース別のラジコン操作ベストを保存します。自動アクセル時代とは操作条件が異なるため、旧記録は上書きしません。保存禁止・不正データでも画面内の記録を保持し、失敗を表示します。荷物集めは記録対象外です。旧コース編集データも削除・更新しません。

## 検証

`node tests/mini-kart-park.cjs` でコース形状の計算を検証します。ラジコン操作の回帰検証はHTTPサーバー起動後に `node tests/mini-kart-rc.cjs`。従来の `mini-kart-park.cjs --browser` とコース編集テストは旧操作仕様用です。

約27度の低めの俯瞰カメラが約2分で一回転します。画面比率と回転角に合わせて、コース全体が見切れない範囲まで拡大します。開始前・一時停止・結果の案内はコースに重ねず、画面下の状態表示にまとめています。「俯瞰回転」で停止・再開できます。カメラの回転は走行操作やタイムに影響せず、一時停止中も景観を眺められます。OSで動きを減らす設定の場合は初期状態で停止します。

`node tests/mini-kart-view.cjs` で俯瞰回転・停止／再開・動きの低減・4方向の投影と操作の独立性・5画面サイズを検証します。

追加コース：「クロスブリッジ8」は中央が上下に分かれた8の字の立体交差、「アップダウンヒル」は高低差のある坂道です。上りは遅く、下りは速くなり、CPも勾配の影響を受けます。立体コースはガードレール付きで、コース外へ落下しません。各コースで3周レース・荷物集め・コース別記録に対応します。

## 天気・時間帯

コース横の選択から昼・夕方・夜・雨を切り替えられます。夕方は暖色の空と光、夜はヘッドライト・テールランプとコース灯、雨は雨粒と路面の反射を描きます。天候は演出のみで、走行条件や記録形式は変わりません。雨はカメラ停止中も動き、OSの動きを減らす設定では静止表示になります。

`node tests/mini-kart-sticks-weather.cjs` で実際のタッチイベントによる2本指操作・アナログ入力・片指解除・後退・キャンセル、天候4種類と5画面サイズを検証します。Chromiumのエミュレーションで、スマートフォン実機とは区別します。

`node tests/mini-kart-countdown.cjs` で旋回率60%（左右・中間入力・後退）、実時間の3・2・1・GO、開始前の停止とタイム除外、入力準備、連打、再開・再プレイ、blurキャンセルを検証します。
