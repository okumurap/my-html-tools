# MINI KART PARK 箱庭カート

更新：2026-10-29（日本時間）。道と仕掛けを編集して試走できる、斜め見下ろしの箱庭カートです。自動アクセルの3周レースと荷物集めを遊べます。HTML・CSS・Canvas・JavaScriptを `index.html` にまとめ、外部ライブラリ・外部通信・ビルドは不要です。

## コースと操作

コースはパークオーバル、リバーSカーブ、ハーバースクエア、サンセットビーンズの4種類です。形状・道幅・景観を変え、同じコース内でベストタイムを比較します。コース変更は開始前・一時停止中・終了後にできます。変更するとレースを最初から準備します。

- 自動アクセル。左右の長押しで走行ラインを変えます
- 左右はカートの進行方向が基準です。各地点の進行方向に直交する右ベクトルを計算して移動し、上・横・下を走るときも入力の意味を統一しています
- PCは←／→、A／D。Spaceまたは中央ボタンで開始・一時停止・再開
- 左右両方を押すと中立。複数のキーや指は個別に管理し、一方を離しても他方の入力を維持します
- タッチ中断・画面を離れたときは入力を解除し、画面のフォーカスを失うと一時停止します

スマホでは操作ボタンとコースを1画面に収め、横向きではコースの横に操作部を配置します。

## CPとレース

3台のCPは、滑らかに左右へラインを変え、前走車が近ければ空いた側を選びます。カーブに合わせた速度調整、前走車との間隔による減速も行います。車体の向きはコースの接線と横移動から描き、横に動く様子も表示します。

周回・順位・タイムを表示します。接触と芝生へのはみ出しは減速し、同じ接触で毎フレーム連続減速しないよう短い猶予を設けています。順位は周回を含む進行距離、ゴール後はフィニッシュ時刻で判定します。ゴールをまたぐフレームは線を通過した時刻へ補間して計測します。レース中断では時間を進めません。

コースの描画・カート位置・CP走行・路外判定は同じ中心線と法線を使っています。距離表で周長に沿って進むため、角度によって速さが不自然に変わるのを防いでいます。道幅は中心線から一定です。各コースの最小曲率半径と境界の交差をテストし、内側が折り返して重なるコースを避けています。

## 記録

`mini-kart-park:records-v2` にコース別のベストタイムとその時の順位を保存します。保存できない場合も画面内の記録を維持し、保存失敗を表示します。壊れた保存データは自動で上書きしません。

旧キー `mini-kart-park:best-v1` は削除・上書きせず、パークオーバルの「以前の記録」として表示します。周回距離・操作・路外判定の基準を変更したため、新しいルールのベストとは分けて保持します。別端末との同期はありません。

## 検証

`node tests/mini-kart-park.cjs` で、独立した4方向の左右ベクトル、楕円の周長、4コースの閉鎖・道幅・最小半径・境界の自己交差を確認します。

HTTPサーバー起動後、`TEST_BASE_URL=http://127.0.0.1:8000 TEST_BROWSER_PATH=/usr/bin/chromium node tests/mini-kart-park.cjs --browser`。Playwright/Chromiumを使い、`TEST_PLAYWRIGHT_MODULE`、`TEST_SCREENSHOT_DIR`に対応します。

4方向の左右操作、実タッチ・2本指・入力の解除・一時停止、CPの左右移動・前走車回避、全4コースの完走、接触・路外減速、ゴール時刻・順位、コース変更、記録の保存・復元・旧キー・破損保護・保存禁止、320/375/768/1280pxと横向き、Pagesのサブパスを検証します。完走・ゴール境界などは本番コードにテスト側だけの観測口を加えて状態を進めています。本番に観測口は含めません。旧版で、右入力が外側へ移動する点とCPの横位置固定を確認済みです。スマートフォン実機は未確認です。

## マイパーク：作る → 試走 → 直す

「パークを作る」で自分の道を編集します。既存4コースと記録は変更しません。8個の番号付きの点をドラッグして道を広げたり縮めたりできます。点をタップし、スライダーやその矢印キーで調整する方法もあります。各点は元の半径の80〜120%まで移動できます。周期Catmull–Rom曲線を使い、256地点の曲率を検査して半径65未満の急カーブになる変更を拒否します。自由な分岐・交差や道路の追加ではなく、閉じた一周コースの形を編集する方式です。

- 「ジャンプ台」「コーン」を選び、道をタップして配置。合わせて24個まで。スタート付近には置けません
- ジャンプ台に乗ると約0.85秒ジャンプし加速。コーンは触れると減速します。空中ではコーン・CPへの接触減速を受けません
- 「消す」で仕掛けをタップして削除。「戻す」は直近40回の編集を取り消します（再読み込みでは履歴を保持しません）
- 「試走する」でその場からレース開始。CPも同じ自作中心線を使って走り、左右にライン変更します。CPはジャンプ台・コーンの効果を受けません
- 走行中でも「パークを作る」で編集へ戻れます。編集へ入ると走行状態はリセットします

道と仕掛けは `mini-kart-park:park-v1` に自動保存。版・半径・曲率・仕掛け種別・位置・個数を検証して復元します。壊れたデータは上書きせず、保存禁止・容量不足では画面内の編集を保持してエラーを表示します。ドラッグ中断・フォーカス喪失ではそのドラッグ前へ戻します。自作コースは編集によって比較条件が変わるため、ベストタイムを保存しません。

## 荷物集め

遊び方を「荷物3個を集めてゴール」にすると、左右に配置された黄色い荷物を集めるモードです。3個すべてを回収してからスタート線を通過するとクリア。取り逃した荷物は次の周で拾えます。既存4コースとマイパークで遊べます。自動アクセルのまま中央を走るだけでは荷物を回収できず、左右のハンドルで走り分けます。このモードはレース記録へ混ぜません。
