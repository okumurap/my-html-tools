# MINI KART PARK 箱庭カート

更新：2026-11-02（日本時間）。7コースでラジコン風の運転を楽しむ箱庭カートです。CP3台との3周レースと荷物集めを遊べます。コース編集機能は削除しました。外部通信・ライブラリ・ビルドは不要です。

## 操作

- 左側の上ボタンでアクセル、下ボタンでブレーキ・後退
- 右側の左右2ボタンで左ハンドル・右ハンドル。旋回は初期設定の48%を維持しています。後退中は旋回方向が反転
- 押している間だけ入力。離すと解除し、アクセルを離すと減速します。下ボタンを押し続けると停止後に後退
- 加速と旋回を2本指で同時操作できます。一方だけ離しても他方の操作は継続。同じ軸の両方を押すと中立
- PCは↑↓ / W Sで加減速、←→ / A Dで旋回。操作ボタンはマウス長押し、フォーカス中のSpace／Enter長押しにも対応
- Spaceまたは中央ボタンで開始・一時停止・再開。新規開始・再プレイは3・2・1・GO!の後に発進。一時停止からはそのまま再開
- カウント中からボタンを押して準備できます。GOまでカート・CPとタイム計測は停止
- フォーカスを失うと入力を解除して一時停止。カウント中に画面を離れるとスタート前へ戻ります
- ゲーム画面の文字選択・長押しメニューを抑止。コース・天候・遊び方の標準メニューは使用できます
- コース・遊び方は停止中に変更できます。変更すると最初から準備します

カートは道の外も走れます。芝生では速度が落ちます。周回はコース上の進行距離で判定します。

## 保存

`mini-kart-park:records-rc-v1` にコース別のラジコン操作ベストを保存します。自動アクセル時代とは操作条件が異なるため、旧記録は上書きしません。保存禁止・不正データでも画面内の記録を保持し、失敗を表示します。荷物集めは記録対象外です。旧コース編集データも削除・更新しません。

## 検証

`node tests/mini-kart-park.cjs` でコース形状の計算を検証します。ラジコン操作の回帰検証はHTTPサーバー起動後に `node tests/mini-kart-rc.cjs`。従来の `mini-kart-park.cjs --browser` とコース編集テストは旧操作仕様用です。

約27度の低めの俯瞰カメラが約2分で一回転します。画面比率と回転角に合わせて、コース全体が見切れない範囲まで拡大します。開始前・一時停止の案内は画面下の状態表示にまとめています。ゴール時は順位・タイム・ベスト（荷物集めでは回収数）の結果パネルを表示し、その場でもう一度走れます。画面を左右にドラッグすると、タッチ・マウスで手動回転できます。ドラッグ中は自動回転を止め、離すとその向きで固定します。「俯瞰回転」で自動回転を再開できます。単なるタップでは停止しません。カメラの回転は走行操作やタイムに影響せず、一時停止中も景観を眺められます。OSで動きを減らす設定の場合は初期状態で停止します。

`node tests/mini-kart-view.cjs` で俯瞰回転・停止／再開・動きの低減・4方向の投影と操作の独立性・5画面サイズを検証します。

追加コース：「クロスブリッジ8」は中央が上下に分かれた8の字の立体交差、「アップダウンヒル」は高低差のある坂道です。上りは遅く、下りは速くなり、CPも勾配の影響を受けます。立体コースはガードレール付きで、コース外へ落下しません。各コースで3周レース・荷物集め・コース別記録に対応します。

## 天気・時間帯

コース横の選択から昼・夕方・夜・雨を切り替えられます。夕方は暖色の空と光、夜はヘッドライト・テールランプとコース灯、雨は雨粒と路面の反射を描きます。天候は演出のみで、走行条件や記録形式は変わりません。雨はカメラ停止中も動き、OSの動きを減らす設定では静止表示になります。

`node tests/mini-kart-buttons-weather.cjs` で実際のタッチイベントによる2本指操作・逆方向同時押し・片指解除・後退・キャンセル、天候4種類と5画面サイズを検証します。Chromiumのエミュレーションで、スマートフォン実機とは区別します。

`node tests/mini-kart-countdown.cjs` で旋回率48%（左右・中間入力・後退）、実時間の3・2・1・GO、開始前の停止とタイム除外、入力準備、連打、再開・再プレイ、blurキャンセルを検証します。

クロスブリッジ8の道幅を約24%、アップダウンヒルの道幅を20%拡張しました。ガードレール内の走行スペースも広がります。以前のベスト記録は保持します。

`node tests/mini-kart-results.cjs` は、修正前に結果が出ないことを再現した上で、ゴール通過後の順位・タイム・ベスト、荷物集めの結果、5画面サイズ、再プレイのカウントダウンとコース変更時の表示解除を検証します。

`node tests/mini-kart-touch-menus.cjs` で文字選択・タッチメニューの抑止と、標準選択メニュー・開始・ボタン長押しの動作を検証します。iPhone Safariなどの実機確認とは区別します。

`node tests/mini-kart-drag-view.cjs` でマウス／タッチの左右ドラッグ、自動回転の停止と再開、タップの区別、アクセルを保持しながらのカメラ操作、キャンセル／blurを検証します。

長押しの拡大表示対策として、ゲーム部分のブラウザ既定タッチ動作と長押しコールアウトを抑止します。標準選択欄とボタンは使えるままにし、選択欄を16px以上にしてiOSのフォーカス時の自動拡大も避けます。ハンドルは直前の設定からさらに20%弱め、初期設定の48%にしています。

追加コース「ハートガーデン」は、左右対称のハートを丸いカーブでつないだ平面コースです。広めの道幅で、上のくぼみと下の先端に鋭い角を作らず、4ボタン操作で走れます。CPとの3周レース・荷物集め・コース別ベスト保存に対応し、既存コースの記録も保持します。

`node tests/mini-kart-heart.cjs` でハートの対称性・くぼみ・先端・曲率を検証します。`--browser` を付けると、実際のデジタル入力による3周完走、荷物集め、結果画面、新旧記録の保持を確認します。
