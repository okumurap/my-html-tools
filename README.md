# My HTML Tools

ブラウザだけで動く、小さなHTMLアプリや便利ツールをまとめて公開するリポジトリです。原則としてビルドやサーバーを必要とせず、PCとスマートフォンの両方で利用できる静的なツールを収録します。

## 公開URL

<https://okumurap.github.io/my-html-tools/>

GitHubリポジトリの **Settings → Pages → Source** は、`GitHub Actions` に設定します。

## アプリ一覧

### 001 Offset Capability Lab

オフセットと標準偏差を調整し、2つの分布のヒストグラムと工程能力指数（Cp・Cpk）を比較するシミュレーターです。

- [アプリを開く](./tools/offset-capability-lab/)
- PC・スマートフォン対応
- Canvas描画、外部通信なし

### 002 図面注釈ツール

PNGまたはJPEGの画像・図面へ、ペン、矢印、図形、連番ラベルを書き込み、PNGとしてコピーまたは保存するツールです。

- [アプリを開く](./tools/drawing-annotation/)
- PC・スマートフォン・ペン入力対応
- Canvas描画、外部通信なし

### 003 スクリュ径A/B比較ツール

射出成形機のスクリュ径A/Bについて、断面積、外周長、最大周速、理論体積流量、充填体積、必要ストロークを比較するツールです。

- [アプリを開く](./tools/screw-diameter-comparator/)
- PC・スマートフォン対応
- 外部通信なし

### 004 でんしゃを走らせよう！

画面をタップして、駅から踏切とトンネルを越えて次の駅を目指すミニゲームです。

- [アプリを開く](./tools/train-crossing/)
- PC・スマートフォン対応
- Canvas描画・効果音、外部通信なし

### 005 坂本電鉄 海岸線

マスコン、ブレーキ、ドア、車内放送を操作して終点を目指す電車運転ゲームです。

- [アプリを開く](./tools/sakamoto-railway/)
- PWA・スマートフォン対応

### 006 レールタウン・レイアウト

線路、駅、踏切、ポイントを自由に配置して、電車を走らせるレイアウトゲームです。

- [アプリを開く](./tools/plarail-layout/)
- PC・スマートフォン対応・端末内保存

### 007 坂本のキス釣り

投げて、海底をさびいて、アタリに合わせる3分間のキス釣りゲームです。

- [アプリを開く](./tools/sakamoto-kiss-fishing/)
- PC・スマートフォン対応・端末内記録

### 008 表整形・編集ツール

Markdown・CSV・TSVの表を読み込み、セル編集、行・列の追加・削除・並べ替え、Undo/Redo、再コピーを行うツールです。

- [アプリを開く](./tools/table-editor/)
- PC・スマートフォン対応
- 外部通信なし、入力データは端末内処理

### 009 コード鍵盤

鍵盤を見て、音を聴いて、実際に押しながら、ピアノコードの構成音を覚える練習ツールです。メジャー、マイナー、7th、maj7、m7、sus4、dimに対応し、構成音クイズも利用できます。

- [アプリを開く](./tools/chord-piano/)
- PC・スマートフォン対応
- Web Audio使用、外部通信なし
- スマートフォンのダブルタップ拡大を抑止

### 010 積立投資シミュレーター

初期投資と毎月の積立額、想定年利、運用期間を設定して資産額・元本・運用損益を概算するツールです。初期値は2,000万円・毎月10万円・年利5%・20年間。スライダーは初期投資100万円、積立5万円、年利1%、期間5年刻みです。

- [アプリを開く](./tools/investment-simulator/)
- PC・スマートフォン対応、外部通信なし
- 年次推移グラフ・詳細表・初期値に戻す機能
- 年利を月次複利に換算し、毎月末積立を仮定。税金・手数料・インフレ・実際の値動きは反映しません

### 011 図面PDF 寸法ID管理

PDF図面上に寸法IDを配置し、図面表記、基準値、公差、分類、測定方法、重要度、備考をまとめて管理するツールです。連続ID登録、CSV入出力、一覧直接編集、Undo/Redo、座標変換済みのID付きPDF出力に対応しています。

- [アプリを開く](./tools/drawing-pdf-dimension-manager/)
- PC・スマートフォン対応
- PDF処理はブラウザ内、単体HTMLで動作

### 012 型締力 Calculator

製品の投影面積から射出成形金型の必要型締力を概算するツールです。長方形、円形、円環、楕円、三角形、台形の面積を寸法から計算でき、複合形状の加算・減算やCAD等で測定した面積の直接入力にも対応します。取り数、ランナー面積、平均キャビティ圧力、余裕率から必要型締力を算出し、成形機の型締力と比較します。

- [アプリを開く](./tools/clamp-force-calculator/)
- 寸法スライダーは1〜200 mm。200 mm超は数値欄から入力可能。取り数は1〜8個
- PC・スマートフォン対応、入力の端末内自動保存、計算書の印刷・PDF保存
- 外部通信なし。型締力は推定平均圧力を用いた概算であり、実機の適合性を保証しません

### 013 人生ダッシュボード

生年月日だけで人生を週単位で眺め、家族・イベント・毎週の充実度を記録するツールです。

- [アプリを開く](./tools/life-dashboard/)
- PC・スマートフォン対応
- 外部通信なし、入力内容はブラウザ内に保存

### 014 GYRO RUSH ジャイロ宇宙船

スマートフォンを左右に傾けて宇宙船を動かし、隕石を回避する120秒のアーケードゲームです。ニアミス・コインでコンボを伸ばし、エネルギーを使った2秒間のハイパーブーストでスコアを伸ばします。3回被弾すると終了します。

- [ゲームを開く](./tools/gyro-rush/)
- ジャイロ・タッチ・キーボード操作、感度調整・効果音設定・一時停止
- ベストスコアと設定は端末内に保存。外部通信なし
- iPhoneでジャイロ操作する場合は、HTTPS上で開始ボタンからセンサーを許可してください

### 015 ぐらぐらクレーン！ SWING CRANE

画面を固定したまま左右ボタンでクレーンを動かし、振り子状の吊り荷の揺れを止める物理演算ゲームです。目標位置への着地精度で得点を競います。ジャイロ操作やセンサー権限は不要です。

- [ゲームを開く](./tools/gyro-crane/)
- 90秒チャレンジ・精密着地・崩壊タワー・強風モードの4種類
- スマートフォンは左右ボタンを長押しして移動、DROPボタンで落下。PCは矢印キーとスペースキーで操作
- 荷物の真下に鉛直方向の点線を表示。効果音、一時停止にも対応
- モード別自己ベストと設定は端末内に保存。外部通信なし

### 016 文字列整形アプリ v7

半角化・全角化・空白整理・行操作・CSV出力など13種類の変換を即時表示。カテゴリー検索、お気に入り、連続変換、変換前後比較、入力への反映を利用できます。

- [アプリを開く](./tools/text-formatter/)
- PC・スマートフォン対応。テーマ・お気に入り・手順のみ端末内に保存
- 入力内容の保存や外部通信なし。変換ロジックの回帰テストあり

### 017 金型の熱膨張 × 公差マップ

20℃基準の穴・凸部の寸法と上下公差、材質ごとの線膨張係数から温度別の自由膨張すきまを概算します。インサートと金型の温度を個別に指定する4条件の判定、256セルの2D温度マップ、目標すきまを満たす凸径上限・必要加熱温度の逆算に対応します。

- [アプリを開く](./tools/thermal-fit-map/)
- PC・スマートフォン対応、条件を端末内に12件まで保存、結果CSV出力
- 外部API・ビルド不要。材料係数の初期値は仮の例示値で、実設計には物性値の確認が必要
- 接触変形や接触圧力を求める機能ではなく、自由膨張に基づく直径方向の概算

### 018 タスク管理

家族共有タスクを「家・その他」「買い物」「子ども」の3つに分類できます。長押しドラッグで分類や並び順を変更、右スワイプで完了、左スワイプで削除。Firebaseを設定するまでは端末内デモとして動作します。

- [アプリを開く](./tools/family-tasks/)
- PC・スマートフォン対応、デモのデータはブラウザ内保存
- 夫婦間・複数端末の同期はFirebaseプロジェクトとFirestoreセキュリティルールを設定してから利用可能

### 019 歯車かみ合いラボ

モジュール・歯数・基準圧力角・転位係数・中心距離をスライダーで変更し、インボリュート歯形、5種類の円、作用線と接触点を可視化する学習用アプリです。歯車の逆回転・接触点アニメーション、切下げ注意、かみ合い率、Before/After比較に対応します。

- [アプリを開く](./tools/gear-mesh-lab/)
- PC・スマートフォン対応、条件の端末内保存、外部通信なし
- 歯元は模式形状・バックラッシは近似値のため製造用歯形や最終設計の保証には使用できません

### 020 モーション寸法計

スマートフォンを物体に当て、測りたい方向へ滑らせた移動量をモーションセンサーから概算する実験ツールです。直線距離・なぞった距離・XYZ成分、軌跡、3辺連続測定、既知寸法による倍率校正に対応します。

- [アプリを開く](./tools/motion-ruler/)
- スマートフォン対応、端末内処理・端末内履歴保存
- iPhone等ではHTTPS上でセンサー権限の許可が必要
- 加速度の二重積分による概算のため、定規・ノギス等の代替や精密測定には使用できません

## ローカルでの開き方

リポジトリのルートでローカルHTTPサーバーを起動します。

```bash
python3 -m http.server 8000
```

ブラウザで <http://localhost:8000/> を開いてください。

## 新しいアプリの追加方法

1. `tools/<app-name>/` を作成します。
2. フォルダ内に最低限 `index.html` を置きます。
3. 必要に応じて `style.css`、`script.js`、`README.md` を追加します。
4. ルートの `index.html` と、このREADMEのアプリ一覧にリンクと概要を追加します。
5. PCとスマートフォンの両方で表示と操作を確認します。

パスはGitHub Pagesで動作するよう、`./tools/example-tool/` のような相対パスを使用します。

## デプロイ

`main` ブランチへのpush、または手動実行により、`.github/workflows/pages.yml` がリポジトリ全体をGitHub Pagesへデプロイします。
