# My HTML Tools

ブラウザだけで動く、小さなHTMLアプリや便利ツールをまとめて公開するリポジトリです。原則としてビルドやサーバーを必要とせず、PCとスマートフォンの両方で利用できる静的なツールを収録します。

## 公開URL

<https://okumurap.github.io/my-html-tools/>

GitHubリポジトリの **Settings → Pages → Source** は、`GitHub Actions` に設定します。

## アプリ一覧

### 001 Offset Capability Lab

オフセットと標準偏差を調整し、2つの分布のヒストグラムと工程能力指数（Cp・Cpk）を比較するシミュレーターです。

規格範囲と平均±3σの図、規格中心からのずれ、Cp/Cpkの計算根拠を確認できます。同じ乱数標本で条件を比べ、再サンプリングで標本を更新します。

- [アプリを開く](./tools/offset-capability-lab/)
- PC・スマートフォン対応
- Canvas描画、外部通信なし

### 002 図面注釈ツール

PNGまたはJPEGの画像・図面へ、ペン、矢印、図形、連番ラベルを書き込み、PNGとしてコピーまたは保存するツールです。前回の図面と注釈を端末内に自動保存し、次回も編集できます。操作画面はダークモード固定です。PCの上段には画像・履歴・PNG操作、下段にはツール・色・太さを配置します。

- [アプリを開く](./tools/drawing-annotation/)
- PC・スマートフォン・ペン入力対応
- Canvas描画、外部通信なし

### 003 スクリュ径A/B比較ツール

スクリュ径A/Bの速度・回転数・射出体積・移動量を換算し、計量完→V-P切替→クッションを共通目盛りで比較します。帯のドラッグでクッション位置をオフセットでき、計量完・V-P・充填率も図と数値で調整できます。

- [アプリを開く](./tools/screw-diameter-comparator/)
- PC・スマートフォン対応
- 外部通信なし

### 004 でんしゃを走らせよう！

ふつう・しんかんせん・きかんしゃを選び、踏切とトンネルを越えて星を集める電車ゲームです。

- [アプリを開く](./tools/train-crossing/)
- PC・スマートフォン対応
- 車体の陰影・乗客・沿線の風景、駅・踏切・トンネルの演出を強化
- タッチで加速・長押しブレーキ・警笛。ルート進行とスピード目安を表示
- Canvas描画・効果音、外部通信なし

### 005 S電鉄 海岸線

マスコン、ブレーキ、ドア、車内放送を操作して終点を目指す電車運転ゲームです。

- [アプリを開く](./tools/sakamoto-railway/)
- PWA・スマートフォン対応
- スマホは景色・速度・次駅・速度推移・操作盤を1画面に配置し、運転中の縦スクロール不要。横向きは景色と操作盤を左右に表示
- 線路・架線・沿線の住宅・海岸を遠近法と陰影で描画。駅ホームも走行位置に合わせて接近
- 雨天は細かな雨筋、窓の水滴、間欠ワイパー、遠景の霞み、濡れた路面を表現
- 景色を少し短くし、速度推移を大きめに常時表示。上部ボタンから拡大。全線・2倍・4倍の区間ズーム、横スクロール、現在地追従に対応

### 006 レールタウン・レイアウト

線路、駅、踏切、ポイントを配置し、3両編成がカーブや分岐をたどるレイアウトゲームです。3D表示に切り替えて視点を回転・拡大し、列車に追従しながら眺められます。

- [アプリを開く](./tools/plarail-layout/)
- 滑らかな曲線走行・駅への減速とドア開閉・編成全体に連動する踏切
- 100〜250%の拡大と表示移動、スマホでも保存・読込に対応
- PC・スマートフォン対応・端末内保存

### 007 Sのキス釣り

海底・巻く速さ・誘いの間を読み、ジャストアワセで大ギスを狙う投げ釣りゲームです。120秒・3分・のんびり・日替わりに対応します。

- [アプリを開く](./tools/sakamoto-kiss-fishing/)
- 巻く速さと誘いの間、藻場の根掛かり、ジャストアワセと丁寧な取り込みの加点
- 水中の光・波・砂底・魚種別の描写を強化
- PC・スマートフォン対応・端末内記録

### 008 表整形・編集ツール

Markdown・CSV・TSVの表を読み込み、形式指定・先頭5行プレビュー、セル編集、行・列の追加・削除・並べ替え、Undo/Redo、再コピーを行うツールです。再読み込み・クリアもUndoでき、スマートフォン向け操作ボタンと任意の端末内保存・復元に対応します。Excelの直接読込、セル番地・列名、改行対応の選択セル編集欄、Excel向けTSVコピーも利用できます。

- [アプリを開く](./tools/table-editor/)
- PC・スマートフォン対応
- 外部通信なし、入力データは端末内処理

### 009 コード鍵盤

鍵盤を見て、音を聴いて、実際に押しながら、ピアノコードの構成音を覚える練習ツールです。メジャー、マイナー、7th、maj7、m7、sus4、dimに対応し、構成音クイズも利用できます。 基本形の押さえる位置・左右の指番号、スマホの音域移動、苦手コードの保存・反復練習にも対応します。

- [アプリを開く](./tools/chord-piano/)
- PC・スマートフォン対応
- Web Audio使用、外部通信なし
- スマートフォンのダブルタップ拡大を抑止

### 010 積立投資シミュレーター

初期投資と毎月の積立額、想定年利、運用期間を設定して資産額・元本・運用損益を概算するツールです。一括・分割・現金保有の比較、暴落シナリオ、目標額からの逆算、インフレ調整、老後の取り崩しにも対応します。

- [アプリを開く](./tools/investment-simulator/)
- PC・スマートフォン対応、外部通信なし
- 年次推移グラフ・詳細表・初期値に戻す機能
- 年利を月次複利に換算し、毎月末積立を仮定。基本・投資方法比較では税金・手数料・インフレ・実際の値動きは反映しません。暴落・インフレ・取り崩しは各追加機能の条件で試算します

### 011 図面PDF 寸法ID管理

PDF図面上に寸法IDを配置し、図面表記、基準値、公差、分類、測定方法、重要度、備考をまとめて管理するツールです。連続ID登録、CSV入出力、一覧直接編集、Undo/Redo、座標変換済みのID付きPDF出力に対応しています。 各IDの図面・詳細編集への移動、未設定の公差・確認方法の抽出、スマホの図面／一覧切替にも対応。

- [アプリを開く](./tools/drawing-pdf-dimension-manager/)
- PC・スマートフォン対応
- PDF処理はブラウザ内、単体HTMLで動作

### 012 型締力 Calculator

製品の投影面積から射出成形金型の必要型締力を概算するツールです。長方形、円形、円環、楕円、三角形、台形の面積を寸法から計算でき、複合形状の加算・減算やCAD等で測定した面積の直接入力にも対応します。取り数、ランナー面積、平均キャビティ圧力、余裕率から必要型締力を算出し、成形機の型締力と比較します。寸法連動の投影図、製品・ランナーの面積内訳、数値入り計算過程も確認できます。

- [アプリを開く](./tools/clamp-force-calculator/)
- 寸法スライダーは1〜200 mm。200 mm超は数値欄から入力可能。取り数は1〜8個
- PC・スマートフォン対応、入力の端末内自動保存、計算書の印刷・PDF保存
- 外部通信なし。型締力は推定平均圧力を用いた概算であり、実機の適合性を保証しません

### 013 人生ダッシュボード

生年月日だけで人生を週単位で眺め、家族・イベント・毎週の充実度を記録するツールです。 今週・今年の位置と直近の予定を確認し、週の振り返り・次週にしたいことをスマホから自動保存できます。

### 014 GYRO RUSH ジャイロ宇宙船

スマートフォンを左右に傾けて宇宙船を動かし、隕石を回避する120秒のアーケードゲームです。ニアミス・コインでコンボを伸ばし、エネルギーを使った2秒間のハイパーブーストでスコアを伸ばします。3回被弾すると終了します。

- [ゲームを開く](./tools/gyro-rush/)

- ジャイロは中央のデッドゾーンなしで滑らかに操作。タッチ・キーボード、感度調整・効果音設定・一時停止にも対応

### 015 ぐらぐらクレーン！ SWING CRANE

夕暮れの港でクレーンを操作し、慣性で揺れる吊り荷を正確に運ぶゲームです。位置・横速度・傾きで着地を採点し、中心への着地と連続成功で高得点を狙います。ジャイロ操作やセンサー権限は不要です。

- [ゲームを開く](./tools/gyro-crane/)
- 90秒チャレンジ・精密着地・崩壊タワー・強風モードの4種類
- スマートフォンは左右ボタンを長押しして移動、DROPボタンで落下。PCは矢印キーとスペースキーで操作
- 風と慣性を含む予測軌道・着地位置・着地可能表示。コンテナ・長尺パイプ・水槽・精密機械で速度と傾きの許容範囲が変化
- タワーは実際に置いた位置が次の土台に。小さい縦画面でも8段積める作業空間を確保
- 港の船・岸壁・鋼製クレーン・吊り具・水面が水平を保つ水槽を描画。効果音、一時停止にも対応
- モード別自己ベストと設定は端末内に保存。外部通信なし

### 017 金型の熱膨張 × 公差マップ

20℃基準の穴・凸部の寸法と上下公差、材質ごとの線膨張係数から温度別の自由膨張すきまを概算します。インサートと金型の温度を個別に指定する4条件の判定、金型温度固定・インサート温度10点の公差帯マップ、目標すきまを満たす凸径上限・必要加熱温度の逆算に対応します。

- [アプリを開く](./tools/thermal-fit-map/)
- PC・スマートフォン対応、条件を端末内に12件まで保存、結果CSV出力
- 条件A/Bの最小・最大すきま、判定、B−Aの差、干渉・目標達成の温度範囲を比較
- 保存条件のJSON入出力。同名は別名で追加し、既存条件を上書きしません
- 外部API・ビルド不要。材料係数の初期値は仮の例示値で、実設計には物性値の確認が必要
- 接触変形や接触圧力を求める機能ではなく、自由膨張に基づく直径方向の概算

### 021 CSV Inspector

CSV / TSVを読み込み、「このデータをそのまま計算に使ってよいか」を短時間で点検するデータ品質チェックツールです。

異常候補から該当セル・周辺行へ移動し、対象の強調と確認ポイントを見ながら順に点検できます。

- [アプリを開く](./tools/csv-inspector/)
- 行数・列数・空欄・重複行・列数不一致・列名の問題を検出
- 数値列の文字混入、日付形式不一致、IQRによる外れ値候補、前後空白・文字化け兆候を表示
- 数値・日時・真偽・カテゴリ・文字列を自動推定し、異常候補をレコード番号つきで確認可能（ヘッダーを1行目として数え、引用符内改行は同じレコード）
- 列の型を指定、必須・数値上下限・複合キーの検査、条件のみを30件まで端末保存
- UTF-8 / Shift_JISを選択して読み込み。CSVの値は変更せず、文字列IDの先頭ゼロを保持
- PC・スマートフォン対応。ファイル内容は外部送信せずブラウザ内で処理

## ローカルでの開き方

リポジトリのルートでローカルHTTPサーバーを起動します。

```bash
python3 -m http.server 8000
```

ブラウザで <http://localhost:8000/> を開いてください。

## 新しいアプリの追加方法

1. `tools/<app-name>/` を作成します。
2. フォルダ内に最低限 `index.html` を置きます。
3. 必要に応じて `style.css`、`script.js`、`README.md` を追加します。
4. `assets/js/catalog.js` の `tools` に一覧データを登録し、このREADMEのアプリ一覧にリンクと概要を追加します。一覧の構造を変えない限り、ルートの `index.html` へのリンク直書きは不要です。
5. PCとスマートフォンの両方で表示と操作を確認します。

パスはGitHub Pagesで動作するよう、`./tools/example-tool/` のような相対パスを使用します。

作業ルールは [AGENTS.md](AGENTS.md) と [tools/AGENTS.md](tools/AGENTS.md)、テストの実行方法は [tests/README.md](tests/README.md)、雛形は [開発参考資料](docs/development-reference.md) を参照してください。
