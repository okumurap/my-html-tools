# 型締力 Calculator

更新：2026-10-23。基本6形状・複合形状・CAD等の直接面積入力から、平均キャビティ圧力と余裕率を用いて必要型締力を概算します。既存の単位は寸法mm・面積cm²・圧力MPa・型締力tf/kNです。

基本形状の投影図は寸法の縦横比と穴径に連動し、着色部分の面積を表示します。寸法が不正なら以前の図を残しません。複合モードの図は追加・減算する候補の形状です。配置情報がないため合成後の位置・重なりを作図せず、合計を符号付き面積の式で示します。直接入力では形状図を表示しません。

合計面積のバーは製品面積×取り数とランナー面積の比です。「面積と型締力の計算根拠」には、製品面積の数値式→取り数とランナー→平均圧力→余裕込み型締力を表示します。形状と計算には既存の面積関数・確定結果を使い、計算式の二重実装や追加依存はありません。印刷には基本形状の数値式も含みます。計算不能時は内訳と式を無効化します。端末保存のキー・データ形式は維持します。

合計面積(cm²)×平均圧力(MPa)÷98.0665＝理論型開き力(tf)、必要型締力＝理論型開き力×(1＋余裕率/100)です。圧力分布・金型や実機の適合性を保証しない概算です。
