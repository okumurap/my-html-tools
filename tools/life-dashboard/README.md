# 人生ダッシュボード

生年月日を入力するだけで、これまでとこれからを週単位で眺められる静的アプリです。初期データに個人情報は含めません。

## 使い方

1. ホームで生年月日を入力します。見通しは90歳を初期値とし、必要なら80・90・100歳から選べます。寿命の予測ではありません。
2. 「編集」で必要な家族やイベントだけ追加します。期間の終了日を空欄にすると現在までを表示します。
3. ホームの「今週と今年」で今週の期間・今年の日数と進み具合、直近の予定・継続中イベントを確認します。生年月日が未入力でも利用できます。
4. 「今週を振り返る」または「今年」で週を選び、充実度・今週の気づき・次週にしたいことを記録します。週のタップは選択のみで、充実度は専用ボタンで指定します。前の年も表示・編集できます。

人生カレンダーは1マス1週間、1行52週間です。行番号は年齢と少しずれます。イベントは生年月日から目安の年齢までの範囲に表示します。残り回数・人生の季節は時間を振り返るための概算です。週の記録は1月1日から7日ずつ区切り、年末の端数を第53週として扱います。

## 保存と公開

外部ライブラリ、アカウント、API設定、ビルドは不要です。入力内容は `life-dashboard:data:v1` キーでlocalStorageに保存し、外部へ送信しません。別の端末やブラウザには同期されず、ブラウザのデータを消すと記録も消えます。旧プロトタイプの保存データは自動で読み込みません。

ルートのGitHub Pagesワークフローで公開できます。ローカルではリポジトリのルートで `python3 -m http.server 8000` を実行し、`http://localhost:8000/tools/life-dashboard/` を開きます。

## 今週の振り返り（2026-10-23）

週の期間は1月1日から7日ごとで、ISO週番号ではありません。年末の第53週はその年の残り1〜2日です。週番号と年の日数は暦日で数えるため夏時間の時計変更に影響されません。今年の進み具合は今日を含む経過日数／年の日数、残り日数も今日を含みます。

メモは入力後350msで自動保存し、「振り返りを保存」でも確定できます。ページを離れる直前の未保存入力も保存を試みます。従来の保存キーと家族・イベント・充実度を引き継ぎ、`reflections` を年・週別に追加しています。破損データを読み込めない場合は元データを上書きせず、既存の「保存データをすべて削除」で明示的に初期化できます。容量不足・保存禁止では入力を画面に維持し、失敗を表示します。

既存のパネル切替・予定表示・端末保存を拡張し、外部依存は増やしていません。主要な回帰対象は生年月日からの週表示、家族・イベント編集、過去の充実度の復元です。

HTTPサーバー起動後、`TEST_BASE_URL=http://127.0.0.1:8000 node tests/life-dashboard-quality.cjs`。Playwright/Chromium、`TEST_BROWSER_PATH`、`TEST_PLAYWRIGHT_MODULE`、`TEST_SCREENSHOT_DIR`に対応します。旧データ、年・週ごとの保存、自動保存・離脱・初期化、予定、うるう年・夏時間を含む独立した4日付、破損・保存失敗、320/375/768/1280pxを確認します。実機未確認です。
