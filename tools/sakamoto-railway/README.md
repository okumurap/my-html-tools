# S電鉄 海岸線

マスコン・ブレーキ・ドア・車内放送を操作して4.2kmの海岸線を走る電車運転ゲームです。乗務選択、天候、駅ごとの評価と最終成績に対応します。

## スマホの表示

スマホの運転画面は表示領域の高さに合わせ、景色・速度・次駅・操作レバー・ドアを縦スクロールなしで表示します。縦向きは上下、横向きは景色と操作盤を左右に配置します。ブラウザのツールバーやセーフエリアによる表示領域の変化にも追従します。マスコン・ブレーキは上下ドラッグ、ノッチボタン、キーボードで操作できます。

## 速度推移

- スマホでは上部の「速度推移」ボタンからパネルを開き、「閉じる」またはEscapeで運転画面へ戻れます。パネル表示中も運転と記録は継続します。PCでは操作盤の下の「速度推移・運行記録」を開閉できます。
- 「全線」「区間 2倍」「詳細 4倍」で横方向に拡大。左右のスワイプ、スクロールバー、トラックパッド等で区間を移動できます。
- 青は実速度、黄の破線は制限速度、赤の線は現在地。縦軸はスクロールしても表示され、表示距離範囲を下部に示します。
- 初期状態では現在地を追従します。グラフへのタッチや手動スクロール操作で追従を停止し、「現在地を追う」で再開できます。
- グラフはゲーム内の表示値・走行距離から記録します。既存の制限速度区間と駅位置を再利用し、運転物理・採点式は変更していません。
- 最初から・再プレイ・乗務開始で走行履歴をリセットします。履歴と表示倍率は保存しません。

## PWAと検証

ホーム画面に追加済みの場合も、再読み込み後に新しいキャッシュへ更新します。既存の乗務選択の保存形式を維持しています。追加の外部通信・ライブラリはありません。

ローカルHTTPサーバーとPlaywrightを使って `node tests/sakamoto-railway.cjs` を実行します。`TEST_BASE_URL`、`TEST_PLAYWRIGHT_MODULE`、`TEST_BROWSER_PATH`、`TEST_SCREENSHOT_DIR` で検証環境を指定できます。スマホ実機の確認とは別に、320×568からの縦向き、568×320・812×375の横向き、画面回転・表示領域縮小・セーフエリア相当の余白を含むエミュレーションを検証します。ページのスクロール量だけでなく、主要ボタンの位置と遮蔽も確認します。
