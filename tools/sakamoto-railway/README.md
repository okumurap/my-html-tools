# S電鉄 海岸線

マスコン・ブレーキ・ドア・車内放送を操作して4.2kmの海岸線を走る電車運転ゲームです。乗務選択、天候、駅ごとの評価と最終成績に対応します。

## スマホの表示

スマホの運転画面は表示領域の高さに合わせ、景色・速度・次駅・速度推移・操作レバー・ドアを縦スクロールなしで表示します。縦向きは上下、横向きは景色と操作盤を左右に配置します。ブラウザのツールバーやセーフエリアによる表示領域の変化にも追従します。マスコン・ブレーキは上下ドラッグ、ノッチボタン、キーボードで操作できます。

## 運転風景

線路・枕木・架線柱・沿線の住宅・樹木・海岸道路を、距離に応じた遠近法でCanvasに描画します。走行距離に連動して流れ、停車中は静止します。各駅の位置にはホームが近づいてきます。陰影、バラスト、草地、海面、遠景の霞を描き分け、晴れ・雨・夕方の既存表示に対応します。画像や3Dライブラリの外部読み込みはありません。

雨天は曇り空、遠景の霞み、濡れた路面、細かな降雨と窓を伝う水滴を描きます。走行速度に応じて雨筋が傾き、間欠ワイパーが水滴を払います。雨の動きは停車中も続きます。端末の「視差効果を減らす」等の設定では、雨粒・水滴を静止し、ワイパーを停止位置に保ちます。雨の演出は景色の中だけに表示します。

## 速度推移

- スマホでは景色を少し短くし、操作盤の上に大きめの速度推移を常時表示します。画面の高さに応じてグラフ枠を112〜160pxに調整します。上部の「グラフ拡大」から詳しいパネルを開き、「閉じる」またはEscapeで小さなグラフへ戻れます。表示の切替中も運転と記録は継続し、倍率・追従設定を引き継ぎます。PCでは操作盤の下の「速度推移・運行記録」を開閉できます。
- 「全線」「区間 2倍」「詳細 4倍」で横方向に拡大。左右のスワイプ、スクロールバー、トラックパッド等で区間を移動できます。
- 青は実速度、黄の破線は制限速度、赤の線は現在地。縦軸はスクロールしても表示され、表示距離範囲を下部に示します。
- 初期状態では現在地を追従します。グラフへのタッチや手動スクロール操作で追従を停止し、「現在地を追う」で再開できます。
- グラフはゲーム内の表示値・走行距離から記録します。既存の制限速度区間と駅位置を再利用し、運転物理・採点式は変更していません。
- 最初から・再プレイ・乗務開始で走行履歴をリセットします。履歴と表示倍率は保存しません。

## PWAと検証

ホーム画面に追加済みの場合も、再読み込み後に新しいキャッシュへ更新します。既存の乗務選択の保存形式を維持しています。追加の外部通信・ライブラリはありません。

ローカルHTTPサーバーとPlaywrightを使って `node tests/sakamoto-railway.cjs` を実行します。`TEST_BASE_URL`、`TEST_PLAYWRIGHT_MODULE`、`TEST_BROWSER_PATH`、`TEST_SCREENSHOT_DIR` で検証環境を指定できます。スマホ実機の確認とは別に、320×568からの縦向き、568×320・812×375の横向き、画面回転・表示領域縮小・セーフエリア相当の余白を含むエミュレーションを検証します。ページのスクロール量だけでなく、主要ボタンの位置と遮蔽、グラフの高さ、晴天での停車中の景色の静止と走行時の変化、雨天の動きと視差効果低減設定、天候切替時の表示復帰も確認します。
