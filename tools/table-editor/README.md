# 表整形・編集ツール

Markdown・CSV・TSVをブラウザ内で編集します。外部通信はありません。

- 自動判定または形式指定、先頭5行のプレビュー後に読み込みます。
- セル編集、行・列の追加・削除・移動、Markdown/TSVコピーに対応します。
- CSVの引用符・セル内カンマ・改行、Excelなどからの複数セル貼り付けに対応します。
- ダーク／ライトモード切り替えに対応します。
- セルをタップして「セル編集」「行操作」「列操作」を使えます。列名は「列名編集」で変更します。
- 再読み込み・クリアを含め、直近80操作のUndo/Redoに対応します。
- 「今の作業を保存」または任意の自動保存で、表と行列順をこのブラウザに保存します。初期設定では表を保存しません。
- 再度開いたとき「前回の作業を復元」で復元します。Undo履歴は再起動後に引き継ぎません。
- 保存容量不足時はエラー表示します。「端末の保存を削除」は編集中の表を消しません。
- 従来のテーマ保存キーは維持します。表の保存キーは `table-editor:draft:v1` です。
