# 010 図面PDF 寸法ID管理

PDF図面上に寸法IDを配置し、寸法情報と公差を管理するブラウザアプリです。

## 主な機能

- PDFのページ表示、拡大縮小、移動
- 図面上への寸法枠とIDの配置
- 連続登録モード（D001、D002…）
- 図面表記、基準値、上下公差、分類、測定方法、重要度、備考の管理
- 最大・最小許容寸法と公差幅の自動計算
- 一覧のセル直接編集
- CSV出力と、既存ID更新・新規追加・全件置換の読込
- Undo/Redo、JSON保存・読込、HTML保存
- ページ回転・CropBoxを考慮したID付きPDF出力

PDFと寸法データはブラウザ内で処理され、外部へ送信されません。
