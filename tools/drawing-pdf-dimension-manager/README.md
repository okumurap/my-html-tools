# 図面PDF 寸法ID管理

PDF図面上に寸法IDを配置し、寸法情報・公差と確認方法を管理するブラウザアプリです。

## 主な機能

- PDFのページ表示、拡大縮小、移動と寸法枠・連続ID（D001、D002…）の登録
- 図面表記、基準値、上下公差、寸法種別（旧「分類」）、測定器・詳細（旧「測定方法」）、重要度、備考の管理
- 確認方法による色分け：3次元測定（表・青）、3次元測定（裏・橙）、汎用測定、画像・投影測定、金型精度で代替確認、測定対象外。カテゴリの追加・色・名前の変更にも対応
- 表／裏を含む確認方法で一覧とPDF上のマーカーを絞り込み、「3次元すべて」で一括表示
- 連続登録時の確認方法を固定可能。ID枠・IDラベル・一覧行の色を連動
- 最大・最小許容寸法と公差幅の自動計算、一覧の直接編集
- 確認方法を含むCSV出力・読込、Undo/Redo、JSON保存・読込、状態を含むHTML保存
- ページ回転・CropBoxを考慮した、確認方法別の色付きID PDF出力

従来のJSONやCSVは読み込み時に既存の寸法情報を維持し、新設の確認方法は未設定として扱います。既存の測定方法欄から表／裏を推測して自動分類することはありません。

**注意：**「金型精度で代替確認」は、金型測定などの根拠による確認区分です。樹脂の収縮や反り、成形条件による寸法変化があるため、金型精度だけで製品寸法が自動的に保証されるわけではありません。適用可否を個別に判断してください。

PDFと寸法データはブラウザ内で処理され、外部へ送信されません。

## 一覧と図面の移動（2026-10-23）

各IDの「図面」で該当位置へ移動し、「編集」で詳細を開けます。選択中の図面にも「一覧へ」「詳細編集」を表示し、一覧の前後ボタンは絞り込み中のIDだけを移動します。スマートフォンでは図面と一覧を切り替えて表示領域を確保します。

「公差未設定」「確認方法未設定」「未設定あり」で対象を抽出できます。公差は上下どちらかの空欄も対象とし、0は入力済みとして扱います。確認方法は色分けカテゴリの選択状態で判定し、自由記入の「測定器・詳細」は任意です。未設定表示は入力漏れの確認用で、公差や検査方法の適否を判定するものではありません。検索・確認方法による絞り込みも併用できます。

絞り込み状態は表示用で、JSON・CSV・HTML保存やID付きPDF出力の対象を削減しません。保存形式は従来のversion 4を維持しています。
