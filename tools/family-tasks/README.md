# ふたりのタスク（家族共有のみ）

公開URL: https://okumurap.github.io/my-html-tools/tools/family-tasks/

Clearのジェスチャー操作を参考にした、共有タスクだけの軽量リストです。Clearの公式製品・連携アプリではありません。新しい依存ライブラリやビルドは使っていません。

## 操作

- 右下の＋または一覧を下へ引いて追加フォームを開き、タイトルを入力して Enter で登録。フォームを閉じず続けて追加できます。必要時だけ「期限・メモ」を展開します。
- タスクを右へスワイプして完了／未完了、左へスワイプして削除（確認あり）。チェックボタンでも完了操作、タスク名タップで編集・期限変更・削除ができます。
- タスクのどこでも長押しして上下にドラッグし、手動順を保存できます。PCではマウス長押し、キーボードは項目を選び Alt＋↑／↓で移動できます。移動中の文字選択・長押しコピーを抑制します。通常の縦スクロールは長押し前に行えます。
- 「未完了 → すべて → 完了」をタップで切り替えられます。検索、カテゴリ、担当、公開範囲の絞り込み、並び替え用のボタンはありません。

## 旧データと家族共有

既存のlocalStorageキー `family-tasks:demo:v1`、データ形式 `version:1`、タスクの各種プロパティは維持します。**旧「自分だけ」のタスクは自動共有・削除・上書きせず、一覧から非表示**にします。設定→JSON保存には旧個人タスクも含まれるため、必要ならバックアップで回収できます。JSON読込はデモのみ、全件置き換え前に確認を表示し、壊れたJSONは拒否します。初期サンプルは架空の共有タスクです。

Firebase接続時は `families/{familyId}/tasks` のみ購読し、新規タスクは `scope:'shared'` として保存します。ユーザー専用コレクションは読み書きしません。家族スペースの作成・UID招待とGoogleログインは設定に残しています。既存の `../../assets/js/firebase-shared.js`、Web SDK v12.19.0、Firestoreルールの必須フィールド・`sortOrder` を再利用します。共通設定 `my-html-tools:firebase-config:v1` も維持。Firebaseを使う前に同梱 `firestore.rules` を既存ルールと統合してFirebase Consoleで適用・権限検証してください（GitHubに置くだけでは反映されません）。Firebaseとデモのデータは相互に自動移行しません。誤ったUIDの招待に注意してください。

## 動作検証・制限

架空データで追加、連続入力、編集、期限、完了・復帰、削除キャンセルと確定、長押し移動、再読み込み後の順位、旧個人タスク非表示・保持、JSON互換、スマートフォン相当のスワイプを検証対象とします。幅320・375・768・1280pxの横はみ出しと実行時エラーを検査します。実機iPhone SafariおよびFirebase実アカウント・夫婦間同期・Security Rules Emulatorの検証は別途必要です。Firebaseのキャッシュはログアウト後も端末に残る可能性があります。JSONのFirebase書き出しは取得済み共有タスクだけで、完全なクラウドバックアップではありません。

以前の `script.js`・`enhancements.js`・`streamlined.js` は公開済み旧版の参照用としてリポジトリに残していますが、新画面からは読み込みません。既存のデータモデル・同期モジュール・保存キーを再利用し、Undo/Redoやグラフは用途外なので追加していません。
