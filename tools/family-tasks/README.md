# タスク管理（家族共有のみ）

公開URL: https://okumurap.github.io/my-html-tools/tools/family-tasks/

家族共有のタスクをジェスチャーで扱うシンプルなアプリです。Clearの操作を参考にしていますが、公式製品や連携アプリではありません。新しい依存ライブラリやビルド環境は使っていません。

## 使い方

- 右下の「＋」か下方向への引っ張りで追加。タスク名のみで連続登録でき、期限・メモは必要な場合にだけ設定します。新しいタスクは「家・その他」グループで始まります。
- タスクを**長押し**すると画面下に「家・その他」「買い物」「子ども」の3つの移動先が現れます。いずれかにドロップすると分類が保存され、一覧も3グループに分かれます。タスク同士へのドロップはこれまでどおり順序変更です。
- ドラッグが使えない場合は、タスク名をタップして編集画面内の「分類」を切り替えられます。分類は選択した時点で保存します。PCでは以前と同じ Alt＋↑／↓ で順序変更できます。
- 右スワイプで完了／未完了、左スワイプで確認付き削除。タスク名タップで編集、期限・メモの変更ができます。「未完了→すべて→完了」の切り替えも維持します。

## 保存と旧データ

保存キー `family-tasks:demo:v1`、バックアップの `version:1`、Firestoreのコレクションとルールを変更しません。分類には既存のカテゴリフィールドを再利用し、保存値は `家`・`買い物`・`子ども` の3種類です。旧 `その他`・`仕事`・`家事`・`住宅` は「家・その他」、旧 `子育て` は「子ども」に**表示上のみ**振り分けます。移動操作や編集画面で別のグループを選択するまでは、元データを勝手に変更しません。新しいタスクは互換性のため `その他` として作成し「家・その他」に表示します。

以前の「自分だけ」のタスクは引き続き一覧から非表示で、デモのJSONバックアップには保持します。勝手に共有化・削除・書き換えはしません。デモからFirebaseへの自動移行はありません。

Firebaseでは家族共有コレクション `families/{familyId}/tasks` のみを購読し、分類変更も既存ルールで許可されるカテゴリ値を使用します。分類表示用に同じコレクションの購読を追加しています。Firebase Consoleで同梱の `firestore.rules` を既存ルールと統合・適用し、権限を確認してください。GitHubのルールファイルだけでは適用されません。

## 検証・制約

分類UIのローカルブラウザ試験では、Chromiumの幅320・375・768・1280pxで旧カテゴリの表示、3つのドロップ先、ドロップ保存・キャンセル、編集画面での分類、個人データ保持、横はみ出しとJavaScriptエラーを確認しています。元のアプリ本体 `clear-app.js` を含む公開URLでの統合試験、iPhone Safari実機、Firebase本番接続・夫婦間同期、Firestore Rules Emulatorの検証は別途必要です。

既存の `clear-app.js` のジェスチャーと保存キー、`../../assets/js/firebase-shared.js` のFirestore初期化を流用しました。`categories.js` は分類表示と分類保存だけを追加するUIレイヤーです。グラフとUndo/Redoは用途外のため追加しません。
