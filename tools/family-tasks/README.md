# 暮らしのタスク

公開URL: https://okumurap.github.io/my-html-tools/tools/family-tasks/

タスクの追加・完了・手動並び替え・任意の期限設定に絞った家族用アプリです。Firebase未設定では、このブラウザのlocalStorageだけに保存するデモです。デモは端末間で同期されません。

## 操作

- 右下の「＋」からタスク名だけで追加できます。追加画面の「詳細設定」では公開範囲・期限・メモを指定できます。担当とカテゴリの選択はありません。
- 一覧の「公開範囲」をタップすると **すべて → 家族共有 → 自分だけ → すべて**、「状態」をタップすると **未完了 → すべて → 完了 → 未完了** の順に切り替わります。検索欄と期限による絞り込みは廃止しました。期限自体の設定・変更は追加画面と編集画面で引き続き可能です。
- **並び替えは常時有効**です。タスクのどこでも長押しして上下にドラッグできます。専用の「↕」と↑↓ボタン、および並び替えモードは表示しません。短いタップでチェック・編集が使え、スクロールしようと動かしたときには長押しを中止します。PCではタスク自体をキーボードで選択し、`Alt + ↑ / ↓` でも移動できます。並び順は`sortOrder`で保存します。
- 「編集」でタスク名・期限・メモと、公開範囲の**家族共有 ⇔ 自分だけ**を変更できます。相手から見える／見えなくなることを確認してから保存します。タイトル・期限・メモ・完了状態・並び順は引き継ぎます。
- 「設定」からデモのJSONを書き出し／読み込みできます。読み込みはデモ専用で、2MB・1000件が上限です。

## 保存・互換性・公開範囲の移動

保存キー`family-tasks:demo:v1`とJSON`version: 1`は変更しません。過去のカテゴリ・担当・並び順を消去しません。旧カテゴリの読み替えも継続します。旧表示順設定は起動時に手動順へ切り替えます。検索・期限絞り込み用の内部要素は互換性のため非表示で保持し、常に検索なし／期限絞り込みなしとします。

Firebaseでは個人と家族共有の保存先が別コレクションです。公開範囲変更時は元データを読み、Firestoreの一括書き込みで新しい保存先への作成と元の削除を同時に行います。移動先では新しいIDを使います。家族共有にするには家族スペースが必要です。公開範囲の変更はオンライン時に実行してください。エラー時は編集画面に表示し、元タスクを残します。

## Firebaseを利用する場合

1. Firebase ConsoleでWebアプリを作成し、AuthenticationのGoogleプロバイダと承認済みドメイン`okumurap.github.io`を登録します。
2. Firestoreを作成し、同梱`firestore.rules`を**既存のルールと統合し、Firebase Consoleで適用・検証**してください。GitHubに置くだけでは反映されません。
3. アプリ設定にWeb用`firebaseConfig`のJSONを貼り付けます。必須項目は`apiKey`、`authDomain`、`projectId`、`appId`です。秘密鍵や個人情報はリポジトリにコミットしないでください。
4. 家族がそれぞれGoogleアカウントでログインし、家族スペースを作成した側が相手のUIDを確認して登録します。UIDを間違えると別人に共有するおそれがあります。

個人タスクは`users/{uid}/tasks`、共有タスクは`families/{familyId}/tasks`、共通設定キーは`my-html-tools:firebase-config:v1`です。JSONは取得済みデータのみの書き出しでFirebaseの完全バックアップではありません。通知・PWA・Undo/Redo・デモからFirebaseへの一括移行はありません。
