# 暮らしのタスク

公開URL: https://okumurap.github.io/my-html-tools/tools/family-tasks/

タスクの追加・完了・手動並び替え・任意の期限設定に絞った家族用アプリです。Firebaseを設定しなければデモとして、このブラウザのlocalStorageだけに保存します。デモは端末間で同期されません。

## 操作

- 画面右下の「＋」から、タスク名だけで追加できます。「詳細設定」を開くと、公開範囲・期限・メモも入力できます。担当とカテゴリは選びません。
- **手動並び替えは常時有効**です。各タスクの「↕」を長押しして上下にドラッグするか、↑↓ボタンを押します。「並び替えモード」や期限順・新しい順への切り替えはありません。絞り込み中の↑↓も、画面に表示されているタスク同士で入れ替えます。並び順はデモでは端末内に保存され、Firebaseではタスクの`sortOrder`を更新します。ドラッグ中はタスク本文の文字選択を抑制します。
- 「編集」ではタスク名・期限・メモに加え、**公開範囲を後から「家族共有」⇔「自分だけ」に変更**できます。相手から見える／見えなくなる影響を確認してから保存します。タイトル・期限・メモ・完了状態・並び順は維持します。
- チェックボックスで完了／未完了を変更し、検索・公開範囲・状態・期限で絞り込めます。設定からデモ用JSONバックアップ／復元ができます（2MB、最大1000件）。

## 保存・互換性・公開範囲の移動

デモの保存キー`family-tasks:demo:v1`とJSON`version: 1`は変更しません。以前の担当・カテゴリ・手動順位は既存データから削除せず、画面上の担当・カテゴリ選択だけを廃止しています。新規タスクは内部的にカテゴリ「その他」、家族共有の担当「共同」を使用します。旧カテゴリも必要に応じて現在の4カテゴリへ読み替えます。以前の「期限順／新しい順」設定は、タスク自体を変更せず手動順へ切り替えます。

Firebaseでは「自分だけ」と「家族共有」は別コレクションです。公開範囲を変更するときは、元ドキュメントを読み、Firestoreの一括書き込みで新しい保存先への作成と元の削除を同時に行います。元のタスクを上書きせず移動先には新しいIDを発行します。家族共有にするには家族スペースが必要で、オンライン時に操作してください。ルール違反や保存失敗時には編集画面にエラーを表示し、元のタスクは残します。

## Firebaseを利用する場合

1. Firebase ConsoleでWebアプリを作成し、AuthenticationのGoogleプロバイダと承認済みドメイン`okumurap.github.io`を登録します。
2. Firestoreを作成し、同梱の`firestore.rules`を**既存のルールと統合して、Firebase Consoleで適用・検証**してください。リポジトリに置くだけではルールは反映されません。他のアプリのルールを上書きしないでください。
3. アプリの「設定」にWeb用`firebaseConfig`のJSONを貼り付けます。必須項目は`apiKey`、`authDomain`、`projectId`、`appId`です。サービスアカウントや秘密鍵、個人情報は絶対に公開リポジトリへ含めないでください。
4. 家族それぞれがGoogleアカウントでログインし、家族スペースを作成した側が相手のUIDを確認して登録します。誤ったUIDでは別人に共有されるおそれがあるため注意してください。

個人タスクは`users/{uid}/tasks`、共有タスクは`families/{familyId}/tasks`に保存されます。共通設定は`my-html-tools:firebase-config:v1`、共通モジュールは`../../assets/js/firebase-shared.js`です。JSONの書き出しは取得済みデータのみでFirebaseの完全バックアップではありません。通知、PWA、Undo/Redo、デモからFirebaseへの一括移行はありません。

## 確認状況

Chromiumの320・375・768・1280pxで、常時並び替え・絞り込み中の上下移動・追加・編集・完了・公開範囲の双方向変更とキャンセル・横スクロールなし・JavaScript実行エラーなしを確認しました。タッチ相当の長押しドラッグ、文字選択抑制、並び順の再読み込み復元、Firebaseの一括移動のモック成功／失敗も確認しています。iPhone Safari実機、Firebase本番接続・夫婦間同期、Firestore Rules Emulatorは未確認です。
