# コード鍵盤

更新：2026-10-23（日本時間）。コードを選び、見て・聴いて・押して構成音を練習する単体HTMLアプリです。追加ライブラリ・ビルド・外部通信は不要です。

## 押さえる位置と指番号

基本形の具体的な音域（C4〜B5）を表示します。同じ音名を両オクターブ同時に光らせず、鳴らすコードのMIDI音と鍵盤の表示位置を一致させています。「手」で右手／左手の指番号を切り替えられます。1＝親指、2＝人差し指、3＝中指、4＝薬指、5＝小指。3和音は右1・3・5／左5・3・1、4和音は右1・2・3・5／左5・3・2・1を基本形の一例として示します。最適な運指を判定する機能ではなく、手の大きさや前後のフレーズに合わせて調整してください。

スマホでは鍵盤を横スクロールできます。鍵盤上下の余白をスワイプするか「低い音」「高い音」「押さえる位置へ」を利用します。鍵盤上の横ドラッグは従来どおり演奏します。音名・指番号は鍵盤と上の一覧の両方に表示します。

## 苦手の反復練習

「苦手に登録」で手動登録し、「苦手を練習」または問題の「苦手だけ」で再出題します。構成音問題の不正解も自動登録します。3回正解すると苦手から外れ、不正解では回数をリセットします。正解済みの問題を再度「回答する」で重複加点しません。同じコードを練習し直すボタンもあります。

構成音問題は回答後に位置・指番号を表示します。コード名問題は答えを表示した後「分かった」「もう一度練習する」で自己評価します。苦手がなくなった場合は通常出題に戻ります。苦手だけの出題は難易度に関係なく登録済みコードを対象にします。

苦手の記録は `chord-piano:practice:v1`、テーマは従来の `chord-piano:theme` で端末内に保存します。別端末と同期しません。壊れた苦手データは上書きせず、専用の消去ボタンで明示的に初期化できます。保存失敗時も画面内の練習状態を維持し、失敗を表示します。音声が使えない場合も練習できます。

## 検証

HTTPサーバー起動後、`TEST_BASE_URL=http://127.0.0.1:8000 node tests/chord-piano-quality.cjs`。Playwright/Chromiumを利用します。`TEST_BROWSER_PATH`、`TEST_PLAYWRIGHT_MODULE`、`TEST_SCREENSHOT_DIR`に対応。C・Am・Bmaj7の独立した構成音、指番号、実際のタッチ回答、再出題・3回正解、自己評価、保存復元・破損・容量不足、テーマ、4画面幅を確認します。実機の指・音声は未確認です。
