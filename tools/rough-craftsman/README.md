# だいたい職人 — プロトタイプ

「10cmの線」「体内時計で5秒」「水平から45°」の3種目で、目分量と時間・角度の感覚を試すゲームです。各100点、合計300点で職人ランクを判定します。

## 操作

- 長さ・角度：作業台をタップ／ドラッグ。±ボタンまたはPCの左右キーで微調整し、判定。
- 時間：スタート後、5秒と思った瞬間に「ここ！ 止める」。15秒で自動終了。タブを離れた場合はその種目をやり直します。
- 判定後は実測値と誤差、長さ・角度では正解の破線を表示。3種目後に総合結果、再プレイ、結果コピー。
- 長さは画面内の1cm見本が基準の仮想寸法です。画面サイズ・DPIに基づく実寸測定ではありません。角度は画面操作で設定し、モーションセンサーは使いません。

## 採点

`round(max(0, min(100, 100 × (1 − |実測値 − 目標値| / 許容幅))))`。
許容幅は長さ50mm、時間2500ms、角度45°。例：8cmは60点、5.5秒は80点、60°は67点。
合計270点以上が神職人、240点以上が師匠、180点以上が一人前、120点以上が見習い、それ未満は修行中。

## 保存・依存

自己ベストと完了した修行回数を `rough-craftsman:v1` に保存。保存不可でも遊べます。壊れた記録を読み込んだ場合は自動上書きせず、リセット操作まで保存を止めます。進行中の修行は再読み込みでリセット。外部通信・外部ライブラリ・音声・センサー権限・ビルドは不要です。

既存クレーンゲームのPointer Events・pointer captureによる入力処理を参考にしています。独立した小規模アプリのためコードの共通化はせず、一覧の既存登録方式を使用します。

## 検証

リポジトリのルートで `node tests/rough-craftsman.cjs`。ブラウザ検証はローカルHTTPサーバーとPlaywrightを用意し、`node tests/rough-craftsman.cjs --browser`。
`TEST_BASE_URL`、`TEST_PLAYWRIGHT_MODULE`、`TEST_BROWSER_PATH` で接続先・実行環境を指定できます。`TEST_SCREENSHOT_DIR` 指定時は320/375/768/1280pxで画面を保存します。エミュレーションによる確認であり、スマホ実機の確認は別途必要です。
