# 003 射出成形機｜スクリュ径 A/B比較

射出成形機のスクリュ径A/Bについて、射出速度、回転数、概算移動量、射出体積を比較・換算するブラウザツールです。

更新：2026-10-23（日本時間）。

## 主な機能

- スクリュ径を `φ24 / φ28 / φ32 / φ36 / φ45 mm` から選択
- A/Bそれぞれの射出速度、回転数、概算移動量を数値またはスライダーで入力
- 射出速度を編集すると、同じ体積流量になる反対側の速度を換算
- 回転数を編集すると、同じスクリュ周速になる反対側の回転数を換算
- 概算移動量と共通射出体積を双方向に換算
- 断面積、体積流量、スクリュ周速、概算射出時間を表示
- クッション10 mm固定・95％体積充填時の想定V-P切替位置、計量完位置、切替までの前進量をA/B比較

## 初期条件

- 条件A: `φ28 mm`、射出速度 `50 mm/s`、回転数 `150 rpm`
- 条件B: `φ32 mm`
- 射出体積: 条件Aの概算移動量 `50 mm` に相当する体積

## 換算式

- 断面積: `π × D² ÷ 4`
- 体積流量: `断面積 × 射出速度`
- スクリュ周速: `π × D × rpm`
- 概算移動量: `射出体積 ÷ 断面積`
- 概算射出時間: `概算移動量 ÷ 射出速度`

計算はすべてブラウザ内で行い、外部通信は行いません。


## 想定V-P切替位置

共通射出体積 `V`（mm³）は100％充填に使う体積とし、クッション分を含めません。スクリュ断面積を `A = πD²/4`（mm²）とすると、移動量は `S = V/A`（mm）です。位置はスクリュ前進端を0 mmとする残り位置で、射出に伴って減少します。

- クッション位置：`10 mm`（固定）
- 計量完位置：`10 + S` mm
- 95％充填までの前進量：`0.95 × S` mm
- 想定V-P切替位置：`(10 + S) − 0.95 × S = 10 + 0.05 × S` mm

径・体積・A/Bの概算移動量の変更に連動して再計算します。既存の移動量入力は整数表示ですが、これらの位置は丸め前の `V/A` から計算し、表示時だけ小数2桁へ丸めます。体積0では計量完位置・切替位置とも10 mm、前進量0 mmです。圧縮・逆流・材料密度・実機応答などを補正しない幾何学的な目安です。

## 検証

既存の断面積・共通体積・A/B連動処理と表示書式を使い、追加のライブラリや外部通信はありません。主要な回帰対象は、体積⇄移動量の双方向換算、径変更時の再計算、速度・回転数のA/B換算です。

HTTPサーバー起動後、`TEST_BASE_URL=http://127.0.0.1:8000 TEST_BROWSER_PATH=/usr/bin/chromium node tests/screw-diameter-comparator.cjs`。`TEST_PLAYWRIGHT_MODULE` と `TEST_SCREENSHOT_DIR` に対応します。独立した参照値はφ24・10,000 mm³で11.11 mm、φ32・32,000 mm³で11.99 mm、φ45・90,000 mm³で12.83 mm。丸め前計算・双方向連動・0と上限・不正値、320/375/768/1280pxと公開サブパスを確認します。画面とタッチはChromiumエミュレーションで、実機確認は未実施です。
