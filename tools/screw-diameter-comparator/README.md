# 射出成形機｜スクリュ径 A/B比較

更新：2026-10-24（日本時間）。径・射出体積・速度・回転数を換算し、計量完→V-P切替→クッションの位置を図で比較する静的アプリです。外部ライブラリ・外部通信・ビルドは不要です。入力はページを開いている間だけ保持し、端末には保存しません。

## 位置を調整する

- 青／オレンジの帯を左右へドラッグ：その側のクッション位置をオフセット。計量完とV-Pも同じ量だけ移動し、共通体積・充填率は維持します。
- ●クッション：帯と同じ操作です。A/Bそれぞれ独立に0〜200 mmの位置を設定できます。
- ■計量完：その位置までの移動量から共通体積を更新し、反対側の計量完・V-Pも再計算します。
- ◆V-P：その側の切替時の充填率を変更します。位置はクッション〜計量完、充填率は0〜100％です。
- 図の下の数値欄でもクッション・計量完・V-P・充填率を調整できます。帯・各マーカーにTabで移動し、左右キーで0.1 mm、Shift＋左右キーで1 mm、Home/Endで上下限へ変更できます。
- 「クッション10 mm・充填率95％に戻す」は両側の位置設定を初期値へ戻します。径・共通体積・速度・回転数は維持します。

ドラッグ中は目盛りを固定し、図の範囲内で動かします。離すとA/Bに共通の表示範囲を更新します。大幅な変更は数値入力を利用できます。Esc、タッチの中断、ウィンドウのフォーカス喪失ではドラッグ開始時の設定に戻します。図の中はドラッグ優先、図の外は通常どおり縦スクロールできます。

## 換算と初期条件

スクリュ径はφ24・28・32・36・45 mm。初期値はAφ28・速度50 mm/s・150 rpm、Bφ32。体積はAの移動量50 mmに相当する30,788 mm³です。両側のクッションは10 mm、切替時の充填率は95％です。

- 断面積 `A = πD²/4`（mm²）
- 共通の100％充填体積 `V`（mm³）。クッション分を含みません
- 移動量 `S = V/A`（mm）
- クッション位置 `C`（mm）、充填率 `f`（％）
- 計量完位置 `C + S`、想定V-P位置 `C + S × (1 − f/100)`、切替までの前進量 `S × f/100`
- 体積流量 `A × 射出速度`、周速 `πD × rpm`
- 概算射出時間 `整数表示の概算移動量 ÷ 射出速度`（速度0では未定義）

位置は前進端0 mmからの残り位置で、射出時は右→左に減少します。位置図と数値は丸め前の体積・断面積で計算し、表示時に小数2桁へ丸めます。クッションと充填率の調整は小数1桁、体積は整数mm³です。従来の概算移動量の入力・表示は整数を維持しています。共通体積の上限は小さい側の断面積×200 mm（小数切捨て）です。体積0では各条件の3位置がその側のクッション位置で一致し、V-Pのドラッグでは充填率を変えません。

これらは幾何学的な理論値です。樹脂の圧縮・逆流・防止リング・材料密度・実機応答の補正は含みません。

## 目盛りとキャッシュ

目盛りとマーカーは各条件の同じSVG内で描き、A/B共通の横軸を使います。CSS・JavaScriptの読み込みURLには内容ハッシュを付けています。従来の高さ制限による目盛りずれは修正済みで、旧CSSの制限を重ねる回帰テストも維持しています。

## 検証

HTTPサーバーを起動し、Playwright/Chromiumを使って以下を実行します。`TEST_BASE_URL`、`TEST_BROWSER_PATH`、`TEST_PLAYWRIGHT_MODULE`、`TEST_SCREENSHOT_DIR`に対応します。

- `node tests/screw-diameter-comparator.cjs`：従来の独立した3位置・共通体積・双方向換算・速度／回転数・入力境界・タッチ・公開サブパス
- `node tests/screw-position-alignment.cjs`：320/375/768/1280/1920pxの画面上の目盛りとマーカーを0.5px以内で照合。`SIMULATE_STALE_CSS=1`で旧CSSも再現
- `node tests/screw-position-drag.cjs`：帯・マーカー・数値調整、独立した3ケース、A/B連動、実際のタッチイベント、Esc・キャンセル・キーボード・入力中の表示同期・0/上限・4画面幅
