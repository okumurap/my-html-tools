# ぐらぐらクレーン！ SWING CRANE

更新：2026-10-21。HTML・CSS・Vanilla JavaScriptだけで動く、夕暮れの港の荷役ゲームです。センサー・外部API・ライブラリは不要です。

## 遊び方

- 左右ボタンを長押しして台車を移動。早めの切り返しで振り子の揺れを抑えます。PCは矢印キーでも操作できます。
- 点線は切り離した後の予測軌道、半透明の荷物は予測着地位置です。「着地可能」の緑表示を目安にDROP（PCはスペース）で落とします。切り離した瞬間の風による力が落下中続くゲーム上のモデルです。
- 位置だけでなく横速度と傾きも判定。中心7未満・横速度35未満・傾き約5.7度未満でPERFECT。連続成功で得点倍率が最大5倍になります。位置・速度は画面内の論理座標です。
- コンテナ、長尺パイプ、水槽、精密機械で速度・傾きの許容範囲が異なります。精密機械は特に慎重に。失敗時は位置・横速度・傾きの理由を表示します。
- 一時停止ボタンまたはEscで停止。バックグラウンドへの移動でも停止します。短い横画面では縦向きに戻す案内が出ます。

## 4つのモード

90秒チャレンジは時間内の得点、精密着地は5回の得点、崩壊タワーは8段積みを目指します。強風モードは90秒間の変動する風を読んで運びます。タワーは置いた実際の中心が次の土台になり、上段ほど位置の許容範囲が狭まります。小さい画面は描画を縮小し、最上段でも吊り荷が土台の上から落とせる空間を確保します。

## 描画と保存

港の奥行き、船、水面の反射、岸壁、鋼製ガントリーと吊り具、荷物の材質をCanvasで描きます。水槽内の水面は荷物が傾いても水平を保ちます。OSの動きを減らす設定では背景の動き・風の流線・着地の粒子を抑えます。操作と物理運動は維持します。

自己ベストと音設定は既存の `gyro-crane:v1` キーに保存します。従来の `best`・`sound`・`plays` を維持。保存に失敗した場合は表示し、今回の結果は画面に残します。読み込めない保存内容は上書きしません。音が使えない端末では音なしで遊べます。

## 実装・確認

既存の振り子・4モード・ボタン入力・保存形式を継続利用しています。GYRO RUSHと釣りゲームのキャンセル／動きの低減の扱い、共通mobile-touch.cssを確認し、単独で動かせる構成を保ちました。新たな共通ライブラリは追加していません。

ルートでHTTPサーバーを起動し、`node tests/gyro-crane.cjs` または `TEST_BASE_URL=http://127.0.0.1:8000 node tests/gyro-crane.cjs --browser` で検証します。詳細は[テスト案内](../../tests/README.md)。主要な回帰対象は開始→移動→落下→終了・再プレイ、一時停止、4モード、効果音設定と記録です。ブラウザの画面・タッチのエミュレーションで確認し、iPhone/Android実機は未確認です。
