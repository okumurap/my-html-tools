# ギターチューナー

HTTPSでindex.htmlを開きSTART。初回はマイクを許可します。STOPでマイク解放、弦ボタンで対象を固定、「自動」で自動判定に戻ります。タブ非表示・音声中断時はマイクを解放して一時停止し、STARTで再開します。音声の送信・保存は行いません。ビルド・本番ライブラリ不要。GitHub Pagesのサブパスに対応した相対URLです。

## 解析

A4=440 Hz、標準6弦の平均律周波数を使用。Workletは1024入力サンプル単位でPCMを転送し、Workerが12 kHzへ積分間引きしてYIN（累積平均正規化差分）を実行します。1024サンプル（85.3 ms）観測、192サンプル（16 ms）ホップ。FFT最大ピークは使用しません。低い差分値を持つ倍周期を検査して倍音によるオクターブ誤判定を抑制します。基音が完全に欠け、偶数倍音しかない音など物理的に曖昧な信号には限界があります。

RMS・信頼度フィルター、大きな孤立変化の確認、20/65 msの適応平滑化、自動弦選択35 centsのヒステリシスを併用。最後の有効値から240 msで表示を解除。±5 centsで緑、表示範囲±50 cents。解析パラメーターはpitch-detector.jsのCONFIGとTrackerで調整可能。上記は処理設定であり実機の入力から表示までの遅延保証ではありません。

Worklet非対応時はScriptProcessor、module Worker生成非対応時はメインスレッド解析へフォールバックします（この場合は性能が劣る可能性があります）。Workerロード失敗時はエラーを表示し停止。音声補正無効の制約は要求値であり、端末側で無視される場合があります。Safariはユーザーのタップ内でAudioContextを作成・再開します。

既存chord-pianoのWeb Audio操作・safe-area・タッチ設計を調査。発音用処理はマイク解析に適さないため流用せず、独立した実装としました。一覧は既存catalogを利用します。

## 自動検証

```
node tools/guitar-tuner/pitch.test.mjs
python3 -m http.server 8000
# 別ターミナル。Playwrightは検証専用で別途用意
node tools/guitar-tuner/browser.test.cjs
```

ブラウザーテストはTEST_PLAYWRIGHT_MODULE、TEST_BROWSER_PATH、TEST_BASE_URL、TEST_SCREENSHOTを指定可能です。

2026-10-31の結果：

- 6弦×9偏差（0, ±5, ±15, ±30, ±50 cents）×3倍音構成×2ノイズ条件、324ケース成功。最大絶対誤差0.656 cents。基音弱・基音欠落＋奇数倍音を含むケースも検査。
- 無音、ノイズ、小音量、44.1/48 kHz入力、自動切替、手動固定、孤立外れ値、30 cents変化への追従と安定、古い値の解除が成功。
- Chromium模擬マイクで開始・停止・再開・権限拒否が成功。320/375/768/1280pxで主要画面の縦横はみ出しなし、手動／自動選択成功。375pxの日本語スクリーンショットを目視確認。ScriptProcessor代替経路の開始・停止、Pages相当のサブパス（テスト時に配信プレフィックスを除去）でのアセット解決も確認。
- 既存共通回帰テスト10グループ成功。
