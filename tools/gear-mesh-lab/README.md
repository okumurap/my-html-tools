# 歯車かみ合いラボ

モジュール・歯数・基準圧力角・転位係数・中心距離追加量を操作する、外歯平歯車の学習用SVG可視化アプリです。ビルド・外部ライブラリ・外部送信不要。`index.html` をローカルHTTPサーバーで開きます。

- インボリュート歯面、歯先円、歯底円、基準円、基礎円、かみ合いピッチ円、作用線と接触点を描画。歯面は式から生成し、歯元は工具刃先Rを考慮しない模式的な接続です。
- 歯数に応じた逆回転、1コマ再生、表示切り替え、ズーム、条件プリセット、Before/After比較、入力の端末内保存。
- 歯車対の標準歯先高さ1m、歯元高さ1.25m、歯先と歯底すきま0.25m、バックラッシゼロの転位歯車対を基本とし、組立中心距離の追加量は非負とします。
- 計算はKHKの技術資料「Calculation of Gear Dimensions」表4.3。逆インボリュート関数は二分法、かみ合い率は作用線上の接触長／法線ピッチ。中心距離追加によるバックラッシは `2 Δa tan(αw)` の一次近似。
- 切下げは `x_min = 1 - z sin²α / 2` で目安表示。製作可能な歯形の保証、歯元曲線、工具干渉、歯面修整、歯幅、強度、荷重、摩耗、製造公差などの設計検証は対象外です。

参照：https://khkgears.net/gear-knowledge/gear-technical-reference/calculation-gear-dimensions/

保存キー：`gear-mesh-lab:params:v1`。保存できない環境でも使用可能。入力範囲は m=0.5～10、歯数=8～80、基準圧力角=14.5～30°、転位係数=-0.8～1、中心距離追加量=0～min(20,2m) mm。形状が成立しない組合せはエラー表示し、前回計算結果は表示しません。

## ウォームギヤ 3Dラボ（第一段階）

[ウォームギヤ3Dを開く](./worm-3d/)：1条・2条ウォームとホイールの90°直交軸を、ネイティブWebGLの模式形状で回転・拡大・半透明表示します。入力は条数、ホイール歯数、軸方向モジュール、ウォーム基準円直径、ホイール転位係数。減速比・リード・リード角・中心距離・代表直径はKHK表4.23の式で計算し、端末内に条件を保存します。WebGL非対応時は模式図と寸法表へ切り替えます。

**制約：** ホイールの歯面はホブ創成形状ではなく凹面・歯筋の模式表現です。接触点・干渉・バックラッシ・強度・効率・歯形精度は計算しません。製造用には使用できません。描画と計算値を混同しないでください。外部ライブラリ、通信、ビルド不要です。

## ウォーム軸傾斜 3D（独立した学習モード）

[軸傾斜3Dを開く](./worm-3d/axis-tilt.html)：従来の直交軸3D画面を変更せずに、ウォーム軸だけを基準の直交配置から−35°～+35°傾けて観察する別画面です。17°なら2軸のなす鋭角は73°です。傾きはリード角とは別で、1条・2条、歯数、軸方向モジュール、ウォーム基準円直径、模式連動回転、視点ドラッグ、ピンチ拡大、半透明と軸線表示に対応します。保存キーは `gear-mesh-lab:worm-tilt:v1` で、通常版の保存内容は変更しません。

**傾斜時の制約：** 歯形は直交軸用の模式形状を傾けて表示しており、非直交の共役歯面・最適中心距離・かみ合い・接触・干渉は計算していません。中心距離と回転比は直交時の参考値・理想比であり、実設計の検証には使用できません。WebGL非対応時は寸法表示のみ利用できます。
