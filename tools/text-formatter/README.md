# 文字列整形アプリ v7

[アプリを開く](./index.html) · ビルド・サーバー不要で動作する静的HTMLアプリです。

v6公開ページの13種類の変換名を引き継いでいます。元ページの内部JavaScriptは取得できなかったため、意味が分かる形で各変換を再実装し、境界値を自動テストしています。v6とのバイト単位での完全一致は保証しません。

- 全角・半角、空白・改行、行操作、開発・ファイル名の検索・カテゴリ選択
- お気に入りの上部固定、手順を組み替えられる連続変換（最大10件）
- コピー成功状態と、コピー不可時の通知
- 長文プレビューの折りたたみ、単体および連続変換結果の入力反映
- 変換前後の文字数・行数・変更箇所を比較
- 自動・ライト・ダークテーマ。テーマ、お気に入り、展開状態、カテゴリ、変換手順のみ端末に保存
- 入力文字列・変換結果・コピー履歴は保存せず、外部送信もしません

仕様：`半角（すべて）` は全角ASCIIと全角カナを半角化、`半角（英数字・記号・スペース）` は全角ASCII・全角スペースのみ。`全角` はASCII・半角カナを変換します。Markdownチェックは空白行以外の先頭に `- [ ] ` を追加。重複行削除は完全一致・初出順維持、行の昇順は日本語ロケールの自然順です。CSVの引用符付き出力は内部の `"` を `""` に変換します。引用符なしのカンマ区切りはCSVとしてのエスケープを行いません。ファイル名安全化はWindowsの禁止文字・末尾・予約名の一部を処理しますが、すべてのOSの制約を保証するものではありません。

## テスト

リポジトリルートで `node --test tools/text-formatter/transforms.test.cjs` を実行します。DOMを含む動作はブラウザで別途確認します。
