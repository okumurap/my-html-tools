# 坂本のキス釣り 2

GitHub Pages: https://okumurap.github.io/my-html-tools/tools/sakamoto-kiss-fishing/

ビルド・サーバー・外部 API なしで動く釣りゲームです。画面構造は `index.html`、共通の見た目は `style-v2.css`、追加スタイルは `style-v3.css`、現行ゲーム処理は `game-v3.js`。旧 `game-v2.js` は履歴・退避として残しています。`index.html` から読み込むゲーム処理は `game-v3.js` のみです。

## モード

| モード | 制限時間 | 特徴 |
| --- | --- | --- |
| ⚡ 120秒爆釣 | 120秒 | 開始時に魚探が自動発動。短時間向け。 |
| ⏱️ 3分勝負 | 180秒 | 通常のスコアアタック。 |
| 🌊 のんびり | 無制限 | 「釣りを終えて釣果を見る」で結果確定。魚が減ると群れを追加。 |
| 🏆 日替わり | 180秒 | 日本時間の日付に基づく固定初期配置・朝固定。オンラインランキングなし。 |

時間制限のあるモードでは NPC 坂本とのスコア対決を表示します。魚探は周辺の群れを表示し、一定時間後に再使用できます。群れの中心へのキャストで15秒間の爆釣タイムが発生します。連続釣果で1.2・1.5・2倍のコンボ得点が発生し、早合わせ・合わせ失敗・ライン切れなどでコンボが途切れます。2本針は累計8匹で解放されます。低確率で30cm以上の幻のシロギスが出現し、サイズは図鑑に記録されます。

## 操作

1. 「魚探」で魚のいる距離を確認し、海面タップまたはスライダーで狙う距離を選ぶ。
2. 大きなボタンを長押しし、「予測」と「目標」が近づいたら指を離してキャスト。15mから100mまで狙え、狙いとの差が6m以下だと誘引にボーナスが付く。
3. 着底したら長押しで巻き、指を離して止める。「コツコツ」は待機し「ブルブルッ」でボタンをタップする。
4. 掛かったら長押しで巻き上げ、テンションが高い赤ゾーンでは指を離す。緩みすぎた場合は再び巻く。

初回のみ操作ガイドと少し長い合わせ受付が用意されています。初回釣果後にチュートリアル完了を記録します。釣果・図鑑・自己ベスト・初回ガイド状態は旧版と同じ `sakamoto-kiss-v2` キーのブラウザ内 `localStorage` へ保存します。端末・ブラウザ間の同期はありません。

## 確認

`node --check tools/sakamoto-kiss-fishing/game-v3.js` で構文確認。GitHub Actions の `fishing-v3-check.yml` が、ゲームファイルの変更時に構文と参照ファイルを検査します。実機では iPhone Safari などで画面幅・長押し・指を離した際の操作を確認してください。
