# Sのキス釣り — 波とアタリを読む

GitHub Pages: https://okumurap.github.io/my-html-tools/tools/sakamoto-kiss-fishing/

ビルド・サーバー・外部APIなしの投げ釣りゲームです。`index.html`、現行処理 `game-v3.js`、共通ルール `rules.js`、`style-v2.css`・`style-v3.css`・`style-v4.css` を使用します。旧 `game-v2.js` は読み込みません。

海面の反射、遠景、光の差す海中、砂底・藻場、しなる竿、魚種ごとの姿をCanvasに描きます。釣果と図鑑にも同梱SVGの魚を表示します。画像・フォント・ライブラリの外部依存はありません。

## 誘いと取り込み

- **海底を選ぶ**：藻場は根掛かりに注意。かけ上がりには大きめのキスが入りやすい群れを配置します。魚探で魚が残っているかも確かめてください。表示はゲーム内の地形とルールで、実釣の予報ではありません。
- **速さと間**：「ゆっくり」「ふつう」「速く回収」を選択。0.35〜2.6秒ほど短く巻き、0.45〜4.5秒の間を作ると反応が良くなります。ガイドは覚えやすい「短く巻いて1〜3秒止める」です。動かし続けたり長時間放置すると反応が弱くなります。
- **根掛かり**：藻場で速く巻くほどリスク上昇。重くなったら止めましょう。根掛かり中は指を離して約1.1秒、糸を緩めると外せます。連続ヒットは途切れます。
- **ジャストアワセ**：「コツコツ」は待ち、「ブルブルッ」のゲージが緑の帯（受付時間の18〜62%）に入ったら合わせます。通常の受付内でも掛かりますが、ジャストなら魚の基本点の25%を追加。2本針の追い食い確率も上がります。
- **丁寧な取り込み**：魚が走る予兆を見て、赤なら離し、緩いなら巻きます。緑のテンションを維持した時間の割合に応じて最大60点を追加。取り込みの進み具合も表示します。

## モード

| モード | 制限時間 | 特徴 |
| --- | --- | --- |
| ⚡ 120秒爆釣 | 120秒 | 開始時に魚探が自動発動。短時間向け。 |
| ⏱️ 3分勝負 | 180秒 | 通常のスコアアタック。 |
| 🌊 のんびり | 無制限 | 「釣りを終えて釣果を見る」で結果確定。魚が減ると群れを追加。 |
| 🏆 日替わり | 180秒 | 日本時間の日付に基づく固定初期配置・朝固定。オンラインランキングなし。 |

時間制限のあるモードでは NPC Sとのスコア対決を表示します。魚探は周辺の群れを表示し、一定時間後に再使用できます。群れの中心へのキャストで15秒間の爆釣タイムが発生します。連続釣果で1.2・1.5・2倍のコンボ得点が発生し、早合わせ・合わせ失敗・ライン切れなどでコンボが途切れます。2本針は累計8匹で解放されます。低確率で30cm以上の幻のシロギスが出現し、サイズは図鑑に記録されます。

## 操作

1. 「魚探」で魚のいる距離を確認し、海面タップまたはスライダーで狙う距離を選ぶ。
2. 大きなボタンを長押しし、「予測」と「目標」が近づいたら指を離してキャスト。15mから100mまで狙え、狙いとの差が6m以下だと誘引にボーナスが付く。
3. 着底したら長押しで巻き、指を離して止める。「コツコツ」は待機し「ブルブルッ」でボタンをタップする。
4. 掛かったら長押しで巻き上げ、テンションが高い赤ゾーンでは指を離す。緩みすぎた場合は再び巻く。

初回のみ操作ガイドと少し長い合わせ受付が用意されています。初回釣果後にチュートリアル完了を記録します。操作ボタンにフォーカスしたSpace/Enterでも長押し・解除でき、画面のフォーカスを失うと長押しを解除します。釣果・図鑑・自己ベスト・初回ガイド状態は旧版と同じ `sakamoto-kiss-v2` キーのブラウザ内 `localStorage` へ保存します。端末・ブラウザ間の同期はありません。

## 確認

`node tests/kiss-fishing.cjs` で、独立した得点計算3ケース、アワセの帯、海底、誘いの間、根掛かりを照合します。HTTPサーバーとPlaywright/Chromiumを用意し、`TEST_BASE_URL=http://127.0.0.1:8000 TEST_BROWSER_PATH=/usr/bin/chromium node tests/kiss-fishing.cjs --browser` で操作を検証します。`TEST_PLAYWRIGHT_MODULE` と `TEST_SCREENSHOT_DIR` にも対応します。

ブラウザテストは320pxからPC・横向きの表示、実際のタッチによるキャスト・アワセ・取り込みと加点、図鑑の一時停止、終了・再プレイ、保存、日替わり配置を確認します。根掛かり・糸切れ・時間切れの境界はテスト内の明示的な状態設定で確認し、実際の釣り操作とは区別します。スマートフォン実機は別途確認が必要です。

GitHub Actionsの `fishing-v3-check.yml` で構文、参照アセット、共通ルールを継続検査します。
