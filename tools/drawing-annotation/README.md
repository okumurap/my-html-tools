# 002 図面注釈ツール

PNGまたはJPEGの画像・図面へ、ペン、直線、矢印、四角、楕円、連番ラベルを書き込み、PNGとしてコピーまたは保存できるブラウザアプリです。

更新：2026-10-23（日本時間）。

## 主な機能

- ファイル選択、クリップボード貼り付け、ドラッグ＆ドロップによる画像読み込み
- ペン、消しゴム、直線、矢印、四角、楕円、数字ラベル
- 選択ツールによる注釈の移動・変形・削除
- 元に戻す、やり直す
- 全体表示、ホイール・ボタン・キーボードによる拡大縮小
- PNGのクリップボードコピーと保存
- 前回の図面・注釈・ツール設定を端末内に自動保存し、次回復元
- ダークモード固定（図面・注釈・PNG出力の色は維持）
- PC、スマートフォン、ペン入力対応

## 使い方

1. 「画像を開く」からPNGまたはJPEGを選びます。PCでは画像の貼り付けやドラッグ＆ドロップも利用できます。
2. ツール、色、太さを選び、図面上で描画します。
3. 注釈を直す場合は「選択」を選び、移動またはハンドル操作を行います。
4. 完成した画像を「PNGコピー」または「PNG保存」で出力します。

画像と注釈はすべてブラウザ内で処理され、外部へ送信されません。画像は30MB以下、合計2,400万画素以下に対応します。


## 自動保存と復元

IndexedDBの `drawing-annotation:v1` に、最後の1件の元画像（Blob）、編集可能な注釈、色・太さ・ツール、自動番号の次の番号、ラベル枠とペン拡張の設定を保存します。線や図形の確定、移動・変形・削除、Undo/Redo後に保存し、設定変更も自動で保存します。入力途中の番号は確定後に保存します。再表示時は図面全体が見える倍率に調整します。Undo/Redoの操作履歴は同じタブの作業中だけ保持し、次回は保存された最終形状から編集を続けられます。

新しい画像の読み込みに成功すると、前回の保存内容もその図面に置き換わります。読み込みに失敗した場合は現在の内容を残します。同時に読み込んだ場合は最後の画像選択を優先します。保存容量不足・保存禁止でも作業は画面に残り、警告と「再保存」を表示します。読み取れない保存データは自動上書きしません。別タブで保存が更新された場合も、古いタブからの上書きを停止します。

保存先はこの端末・このブラウザだけです。端末間での同期はありません。ブラウザのデータ削除や保存領域の自動整理で失われることがあるため、大事な図面はPNGでも保存してください。操作画面は端末のテーマ設定にかかわらずダークモードで表示し、元画像と注釈には色反転やフィルターをかけません。

## 検証

既存の図面描画・PNG出力を使い、さっとメモの保存失敗・破損データ・別タブ競合への対処を参考にしました。画像Blobを保存するため、localStorageではなくIndexedDBを使います。本番依存の追加はありません。

HTTPサーバーの起動後、`TEST_BASE_URL=http://127.0.0.1:8000 TEST_BROWSER_PATH=/usr/bin/chromium node tests/drawing-annotation.cjs`。再読込復元、復元後の注釈編集、Undo/Redo、PNG一致、端末テーマにかかわらない暗色表示と6画面幅、保存失敗・破損データ保護・別タブ競合・画像読込失敗と競合を検証します。スクリーンショットは `TEST_SCREENSHOT_DIR` で指定できます。Chromiumのエミュレーションであり、実機・ネイティブのペン操作感は未確認です。

PC（1024px以上）は、上段に画像を開く・Undo/Redo・PNGコピー／保存、下段にツール・色・太さを揃えます。全体表示はズームボタンの隣に配置します。スマートフォンの描画操作は引き続き横スクロールで選択します。
