# CSV Inspector

更新：2026-10-23。CSV/TSVの欠損・重複・型・日付・外れ値候補と、列ルール・複合キーを端末内で検査します。CSV本体の外部送信・保存・自動修正は行いません。検査条件だけを任意で保存します。

異常候補の「該当箇所を見る」で元CSVの前後3レコードを表示します。対象セル、列指定のない異常は行全体を強調し、確認ポイントも表示します。前の異常・次の異常・一覧へ戻るで順に確認できます。ヘッダーは1行目、引用符内改行は同じレコードに含みます。大きなCSVは最大25列・各セル先頭1,000文字までをプレビューします。新規解析・解析失敗時は古いプレビューを残しません。

既存の解析結果に元レコードを保持して表示するため、行列の推測や別パーサーへの依存はありません。`tests/csv-inspector-quality.cjs` でセル・行・ヘッダー・列数不一致、引用符内改行、移動と戻る、古い結果の無効化、4画面幅を確認します。共通回帰は `tests/tools-regression.cjs`。実機未確認。
