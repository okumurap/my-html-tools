# でんしゃを走らせよう！ v3

子ども向けの、タップと大きなボタンで遊べる電車ゲームです。PC / スマートフォン対応、静的HTML/CSS/JavaScriptのみで動作します。

## 描画と画面

落ち着いた絵本の色調で、車体の陰影・反射する窓・乗客・回転する車輪を描きます。きかんしゃは前方の煙突と動く連結棒を備えます。重なる山並み、住宅、草花、駅の時計・ベンチ・待つ人、踏切で待つ車、トンネルの照明を加えています。車両選択は同梱SVGイラストです。画像・フォント・ライブラリの外部読み込みはありません。

ルート上の小さな電車が進み具合を示し、運転中はスピードの目安を言葉とバーで表示します。小さな縦向き画面では電車を選択カードの上に配置し、横向きではカードを右側に寄せます。ページの縦横スクロールは不要です。

## 遊び方

1. 「ふつう」「しんかんせん」「きかんしゃ」のいずれかを選び、出発ボタンを押します。
2. 画面の空いた場所か「スピードアップ！」をタップすると速くなります。「ブレーキ」は押している間だけ効き、「プップー！」で警笛を鳴らせます。
3. 踏切、トンネルを抜け、3つのお星さまを集めて駅へ。到着後は次の駅へ進めます。

到着回数、選んだ車両、消音設定はブラウザのローカルストレージに保存されます。音声は最初の操作以降に再生されます。iOS Safariなど全画面APIが使えないブラウザでは全画面にできない旨を案内します。モーション低減設定にも対応しています。

キーボードでは Space/↑ で加速、↓ 長押しでブレーキ、H で警笛を操作できます。

## 検証

`python3 -m http.server 8000` でHTTP配信し、Playwright/Chromiumで `node tests/train-crossing.cjs` を実行します。`TEST_BASE_URL`、`TEST_BROWSER_PATH`、`TEST_PLAYWRIGHT_MODULE`、`TEST_SCREENSHOT_DIR` に対応します。320pxからデスクトップ・横向きの表示、3車種で出発→星収集→到着→再出発、タッチのブレーキ長押しと解除、キーボード、設定の保存、保存・音・全画面APIの利用不能、モーション低減設定、公開サブパスを検証します。スマートフォン実機での確認とは区別します。

保存キー `train-crossing:v2:` と既存の到着回数・車種・音設定は引き継ぎます。共通の `../../assets/css/mobile-touch.css` を利用します。
