# レールタウン・レイアウト

[ゲームを開く](https://okumurap.github.io/my-html-tools/tools/plarail-layout/)

線路・駅・踏切・ポイントを配置して、列車を走らせる静的HTML/Canvasのレイアウトゲームです。HTML・CSS・JavaScriptを `index.html` にまとめています。外部ライブラリや画像・APIの読み込みはありません。

## 作る・走らせる

- パーツを選び、空いたマスをタップして配置。同じパーツをタップすると回転、別のパーツなら上書き。なぞって連続配置、長押しで削除できます。中断されたタッチでは配置しません。
- 「列車」を選んで線路をタップすると列車を置き、もう一度タップすると削除します。最大3編成です。「走らせる」→「出発」で運転し、速度は0.5〜2倍で調整できます。
- 各編成は最大3両。先頭が通った経路を後続車がたどるため、カーブやポイントでも車両が線路に沿って連なります。後方の線路が不足する場所では、走行履歴のある車両から表示します。
- 駅の手前で減速し、中央で約1.7秒停車。ドアの開閉後、滑らかに加速します。停車回数と運転状態を表示します。
- ポイントは運転中にタップして切り替えます。緑の経路と白い矢印が選択中の進路です。編成が通過中のポイントは切り替えできません。進入した車両と後続車は同じ経路を進みます。
- 踏切は接近する列車と編成全体を見て開閉し、最後尾が通り過ぎるまで閉じます。踏切上で一時停止した場合も閉じたままです。
- 接続先がない線路の端では、最後尾側が先頭になって折り返します。3両の位置は保ったまま進行方向を変えます。

## 3Dで見る（2026-10-24）

上部の「3Dで見る」で、現在のレイアウトと列車を立体表示します。線路・枕木・ホーム・屋根・踏切・街並み・車体を3D座標で描画します。現在の平面レイアウトを使い、線路や列車のデータは2Dと共通です。

- ドラッグ：視点を回転。2本指のピンチ、ホイール、＋／−で65〜240％に拡大縮小
- 「回転」を押すとドラッグを平行移動へ切り替え。左／右ボタンで回転、「角度」で見下ろす高さを変更
- 「列車を追う」で先頭編成に追従。手動で平行移動すると追従を解除
- 「全体」で視点・倍率・追従を初期状態に戻す
- Canvasにキーボードフォーカスを移すと、矢印で回転・角度、＋／−で倍率、Homeで全体へ戻せます
- 3Dでも出発・一時停止・速度調整・ポイント切替に対応。通過中のポイントは2Dと同じ条件でロックします

「3Dで見る」は運転画面を開きます。自動では出発せず、運転中ならそのまま走行を続けます。「2Dに戻る」でも位置・走行状態を引き継ぎます。「つくる」を押すと2D編集へ戻り、従来どおり一時停止します。2Dの拡大率・移動位置は維持します。3Dの視点操作は配置やUndo履歴を変更しません。3D視点は保存データに含めず、従来の保存形式を維持します。

3D表示はCanvasで透視投影し、近い面が遠い面を隠す順序で描きます。地面は列車やレールを隠さない専用の描画層に分け、線路・カーブ・列車位置には既存の経路計算を使っています。外部ライブラリを増やさず、単体HTMLで動く構成を維持しています。

## 表示と保存

「＋／−」で100〜250%に拡大・縮小し、「移動」をオンにしてドラッグすると表示範囲を動かせます。オフにするとパーツ配置・ポイント切替へ戻ります。「全体」で全マスを見渡せます。枕木と2本のレール、駅の屋根や乗客、車体の屋根・窓・連結器を描き分けています。

「保存」「読込」はスマホでも上部から操作できます。保存キー `railTownV2` と以前の12×8マス・列車データを引き継ぎます。読込時は列車の走行履歴を現在の線路から再構成します。壊れた保存データは盤面を置き換えずに案内し、保存できなかった場合も表示します。「戻す」で編集履歴を戻せます。表示倍率や移動操作では編集履歴を作りません。

## 検証

`node tests/plarail-layout.cjs` で、独立した曲線中点・直線・弧長を照合します。HTTPサーバーとPlaywright/Chromiumを用意し、`TEST_BASE_URL=http://127.0.0.1:8000 TEST_BROWSER_PATH=/usr/bin/chromium node tests/plarail-layout.cjs --browser` で操作を検証します。`TEST_PLAYWRIGHT_MODULE` と `TEST_SCREENSHOT_DIR` に対応します。

320/375/768px・PC・横向き、3両の曲線走行、駅停車と発車、ポイント通過中のロック、最後尾と踏切、折り返し、複数周回を確認します。タッチでの配置・回転・削除・キャンセル・Undo、拡大と移動、保存・旧形式の読込・不正データ・保存失敗、公開サブパスも確認します。経路・折り返し等の境界はテスト側の明示的な状態設定で検証し、本番にテスト観測口を含めません。スマートフォン実機の確認とは区別します。


3D専用検証は `node tests/plarail-3d.cjs`、ブラウザ操作は `TEST_BASE_URL=http://127.0.0.1:8000 TEST_BROWSER_PATH=/usr/bin/chromium node tests/plarail-3d.cjs --browser`。既存と同じ環境変数・スクリーンショット指定に対応します。独立した投影3ケース・傾斜カメラ・地面の逆投影・手前の面の切り取り、周回線路4辺の可視性、2D/3Dの走行継続、タッチ回転・ピンチ・平行移動・中断・キーボード、追従、ポイントの選択とロック、保存形式、5画面サイズ、96マス・9両と空の配置を確認します。テスト観測口はレスポンスにテスト側だけで追加し、本番に含めません。実機の動作・フレームレートは未確認です。
