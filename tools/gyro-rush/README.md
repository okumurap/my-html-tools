# GYRO RUSH ジャイロ宇宙船

[ゲームを開く](https://okumurap.github.io/my-html-tools/tools/gyro-rush/)

スマートフォンを左右に傾け、隕石を避けて120秒の生還を目指すゲームです。ニアミスとコインでコンボが上がり、3回被弾すると終了します。金属の機体パネル・反射するキャノピー・二基のエンジン噴射、凹凸とクレーターのある隕石、惑星の昼夜と大気の縁をCanvasで描きます。画像・ライブラリの外部読み込みはありません。

## 操作

- **移動**：ジャイロで左右に傾けるか、ゲーム画面の上側を左右になぞります。PCでは左右矢印キーも使えます。
- **ブースト**：横の点線から下、ゲーム画面の下約28%とエネルギー表示を含む範囲は、左・中央・右のどこをタッチしても発動します。50エネルギー消費で2秒間、スコア2倍。発動中やエネルギー不足時は再消費しません。この範囲のタッチでは機体を横移動させません。上側の指で操作しながら、別の指で発動することもできます。
- **キーボード**：Spaceでブースト。領域のボタンへフォーカスしてSpace/Enterでも発動できます。
- **一時停止**：右上の「Ⅱ」またはEscape。ジャイロの中央角度を設定し直したり、タッチ操作へ変更できます。画面の非表示・フォーカス喪失・横向きへの回転では自動停止します。短い横向き画面では縦向きに戻してから再開します。

ジャイロはHTTPSと対応センサーが必要です。権限拒否や未対応の場合はタッチ操作を選べます。許可後もセンサーが応答しない場合はタッチ操作へ切り替えます。実際のセンサーの感度は端末ごとに異なります。

ベストスコア・感度・音設定は以前と同じ `gyro-rush:v1` キーに保存し、既存記録を引き継ぎます。保存や音のAPIが使えなくても遊べます。モーション低減設定では画面揺れ・被弾フラッシュ・ブースト中の星の伸びを抑えます。

## 検証

HTTPサーバーとPlaywright/Chromiumを用意し、`TEST_BASE_URL=http://127.0.0.1:8000 TEST_BROWSER_PATH=/usr/bin/chromium node tests/gyro-rush.cjs`。`TEST_PLAYWRIGHT_MODULE` と `TEST_SCREENSHOT_DIR` に対応します。

320/375/768px・PCで画面とブースト範囲、下部の左・中央・右・フッターへのタッチ、上側の移動との分離、2本指、エネルギー49/50/100、発動中の重複消費、キャンセル、キーボード、一時停止・回転・再プレイ・保存を確認します。センサーは許可拒否・タイムアウト・模擬gamma入力・中央設定を検証します。終了と被弾は明示的な状態設定で境界を確認します。観測口はテスト側で配信レスポンスへ追加し、本番には含めません。スマートフォン実機のジャイロ確認とは区別します。
