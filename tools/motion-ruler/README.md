# モーション寸法計

スマートフォンを物体に当て、始点から終点へ一方向に滑らせた移動量を `DeviceMotionEvent` と `DeviceOrientationEvent` から概算する実験ツールです。

## 現在の仕様

- 測定は1方向のみ
- 動き始めの加速度から測定軸を自動ロックし、以後はその軸成分だけを距離計算に使用
- 1 mm目盛りの仮想スケールを常時表示し、測定中は固定指針の下を目盛りが移動
- 測定中の表示は一方向前進を前提に後戻りを抑制
- 開始前約0.6秒の静止バイアス補正
- 終了後約0.4秒の静止値を使ったセンサーバイアス変化補正
- 終端速度を0と仮定した速度ドリフト補正
- 既知寸法による倍率校正
- 最近8件の測定履歴を端末内に保存

旧版の「なぞった距離」「XYZ成分」「軌跡」「3辺連続測定」は、操作を単純化してドリフト影響を減らすため画面から外しました。既存の保存キー `motion-ruler:v1` と校正倍率・履歴は維持し、旧履歴も表示できます。

## 測定原理と制約

加速度を時間積分して速度、さらに積分して位置を求めます。加速度センサーの微小なオフセットも二重積分で大きな距離誤差になります。そのため、定規・ノギス等の代替や精密測定には使用できません。

測定開始時に静止バイアスを推定し、動き始めの方向を測定軸として固定します。測定中は軸以外の加速度成分を距離計算から除外します。終了ボタン後にも静止値を取得し、開始時からのバイアス変化を測定区間へ線形に補正したうえで、終端速度が0になるよう速度ドリフトを補正します。

長時間、大回転、短すぎる距離、柔らかい面、手持ちでの空中移動では誤差が増えます。机・箱・壁などへ接触させ、始点から終点へ約1秒で一方向に滑らせる用途を想定しています。

## 権限

モーションAPIは対応ブラウザのHTTPS環境で利用します。iPhone等、権限要求が必要な環境では「モーションを有効化」ボタンから許可を要求します。測定値・履歴・校正係数は外部送信せず、ブラウザ内だけで処理します。
