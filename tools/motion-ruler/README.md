# モーション寸法計

スマートフォンを物体に当て、測りたい方向へ滑らせたときの移動量を `DeviceMotionEvent` と `DeviceOrientationEvent` から概算する実験ツールです。

## 主な機能

- 直線距離・なぞった距離・XYZ移動量の表示
- 端末姿勢を使った3D座標への変換
- 測定開始前の静止バイアス補正
- 終端速度を0と仮定した速度ドリフト補正
- 軌跡表示、横ぶれRMS、センサー状態判定
- 既知寸法による倍率校正
- 3辺連続測定と概算体積
- 最近8件の測定履歴を端末内に保存

## 測定原理と制約

加速度を時間積分して速度、さらに積分して位置を求めます。加速度センサーの微小なオフセットも二重積分で大きな距離誤差になるため、定規・ノギス等の代替にはなりません。

測定前に約0.7秒静止してバイアスを推定し、測定終了時にはスマートフォンが静止している前提で、積分された終端速度が0になるよう区間全体へ線形ドリフト補正をかけます。姿勢情報が取得できる場合は、Device Orientation仕様の Z-X'-Y'' 回転行列で端末座標の加速度を基準座標へ変換します。

長時間・大回転・短すぎる距離・柔らかい面・手持ちでの空中移動では誤差が増えます。机、箱、壁などへ接触させ、1〜2秒程度で直線的に滑らせる用途を想定しています。

## 権限

モーションAPIは対応ブラウザのHTTPS環境で利用します。iPhone等、権限要求が必要な環境では「モーションを有効化」ボタンから許可を要求します。測定値・履歴・校正係数は外部送信せず、ブラウザ内だけで処理します。
