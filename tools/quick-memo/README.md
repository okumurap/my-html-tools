# さっとメモ

作成・更新：2026-10-22（日本時間）。開いたらすぐ指で書ける、スマートフォン中心の手書きメモです。初回説明・タイトル入力・新規作成操作はありません。

## 操作

- 指・ペン・マウスで紙に直接書きます。点を打つこともできます。画面全体はスクロールしません。筆記画面の連続タップ・ピンチによるブラウザ拡大を抑制します。保存状態やボタンなどのUI文字は選択されません。画像プレビューの長押し保存は利用できます。
- ペンは4色・3段階。選択中のペンをもう一度押すと設定を開きます。消しゴムからペンに戻るときは1回で切り替わります。
- 消しゴムはなぞった部分だけ消します。選択中にもう一度押すと、表示中のメモの削除確認を開きます。キャンセル可能で、削除直後は「元に戻す」で復元できます。戻す／やり直すは消しゴムにも対応。PCはCtrl/Cmd+Z、Shift+Ctrl/Cmd+Z、Ctrl/Cmd+Yも使えます。
- 「新しい紙」は現在のメモを残して白紙へ。右上の一覧から過去メモを開いて編集できます。空の紙で繰り返し押しても白紙は増えません。
- 一覧のごみ箱で個別削除。確認後もメモの束を開いたまま一覧を更新し、削除後10秒間は一覧内の「元に戻す」で復元できます。
- 一覧の削除ボタン左にある「共有」から、そのカードのメモをプレビューできます。編集中の紙は切り替えず、プレビューを閉じると一覧に戻ります。
- 右上の画像ボタンは編集中の紙のプレビューを開き、PNG保存。対応端末ではファイル共有も選べます。背景は白で、方眼・操作ボタンは画像に含みません。保存できない場合はプレビューを長押しして保存してください。

## 保存

`quick-memo:v1` のlocalStorageに、ページ・線・色・太さ・日時・選択中の紙を保存します。通常は筆記終了時に保存し、画面を離れる際も保存を試みます。通常の保存表示だけは最後の状態変更から0.5秒待って更新し、連続筆記中のちらつきを抑えます。実際の保存は遅らせず、保存失敗の警告はすぐ表示します。次回は最後の紙を開きます。やり直しスタックと削除直後の復元はそのタブを開いている間のみです。データはこのブラウザだけにあり、端末間では同期しません。大事なメモは画像保存してください。

保存禁止・容量不足の場合もメモは画面に残り、警告と再保存ボタンを表示します。読み込み不能・形式不正のデータは上書きしません。その状態で書くメモは画像保存を利用してください。別タブで保存内容が変わると、このタブの保存を停止して競合を表示します。保存前にも現在の保存値を比較します。

1枚30,000点・100枚まで。線を追加できる上限では新しい紙へ案内します。容量はブラウザ設定に依存し、上限枚数より早く保存できなくなる場合があります。入力キャンセル・フォーカス喪失時は書きかけの線を残します。同時に受け付けるポインターは1本。完全なパームリジェクション・筆圧・文字認識・ピンチズームには対応していません。

## 実装と検証

HTML・CSS・Vanilla JavaScript、CanvasとPointer Eventsで実装。外部ライブラリ・外部API・PWAは使用しません。図面注釈ツールのDPR補正・ポインター捕捉・Undo/Redo・PNG出力と、レールタウンの履歴処理を調査しました。画像注釈・図形編集を必要としないため、新規の軽いストロークデータで実装し、既存アプリとの共通化はしていません。

スマホのブラウザのバーの出入りでは用紙が伸縮しないよう、安定したビューポート高（svh、未対応環境はvh）を使います。紙ごとの論理寸法を保持し、画面回転・ウィンドウ変更では表示だけを拡大縮小します。文字の縦横比と線の座標は維持します。UIは淡い方眼紙で、手書きの読みやすさを優先し暗い配色でも紙は明るくしています。

主要な確認対象は、即筆記→保存→復元、新しい紙→一覧→再編集、消しゴム→Undo/Redo、PNG出力→削除→復元です。ルートでHTTPサーバーを起動して `TEST_BASE_URL=http://127.0.0.1:8000 node tests/quick-memo.cjs`。ブラウザの画面・タッチのエミュレーションで検証し、実機の指・Apple Pencilなどの書き味とネイティブ共有は未確認です。詳細は[テスト案内](../../tests/README.md)を参照してください。
